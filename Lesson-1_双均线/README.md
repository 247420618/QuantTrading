# Lesson 1：基础策略实验课

Lesson 1 开始进入可运行策略。每一课都同时包含：

1. **教案**：解释策略假设、公式、适用边界和实验方法；
2. **代码**：用当前 `Tools` 数据接口读取本地 Parquet 或远端 Tushare 数据；
3. **练习**：要求修改参数、比较结果，并记录失败样本。

## 推荐顺序

### 1.1 双均线趋势策略

[开始学习](01-dual-moving-average.md)

用快慢均线构造最基础的趋势跟随策略，重点不是证明它能赚钱，而是练习：

- 如何把口语化规则写成可复现公式；
- 如何把信号转成买入、卖出、持有动作；
- 如何从本金和空仓状态开始做账户级回测；
- 如何避免使用未来数据；
- 如何在 A 股 T+1 约束下把信号延后一日执行；
- 如何比较策略本金涨跌幅和股票自身涨跌幅；
- 如何调用 `DrawingToolkit` 绘制双均线买卖点图和策略对比图。
