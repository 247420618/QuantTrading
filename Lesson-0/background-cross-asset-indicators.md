# A 股量化研究中的跨资产、实体经济与另类指标

> 课程编号：Lesson 0.4
>
> 更新日期：2026-08-06
>
> 适用对象：数学和机器学习基础较强，但刚开始建立金融市场、产业链和跨资产研究框架。
>
> 定位：回答“股票之外的数据与股价有什么关系”，区分机械关系、经济机制、经验相关和伪相关，并给出可以复现的检验方法。本文不是投资建议，历史相关不保证未来收益。

## 1. 问题导入

股票并不在真空中定价。居民存款、房价、利率、汇率、商品、库存、航运和行业经营数据都可能与 A 股同时变化，但“看起来相关”与“能够解释或预测”之间有很长的距离。本课从用户最直观的四组猜想出发，建立跨资产研究的统一语言。

完成本课后，你应当能够：

1. 区分机械关系、经济机制、经验相关和伪相关；
2. 用现金流、成本、融资与风险溢价解释外部变量怎样传到股票；
3. 处理共同趋势、滞后、频率错配、修订和反向因果；
4. 把一个生活化猜想改写成可复现、可否证的研究项目。

### 先给出最重要的结论

#### 有没有方向明确、长期公认的关系？

有，但必须区分三种强度。

| 层级 | 关系来自哪里 | 典型例子 | 稳定性 |
| --- | --- | --- | --- |
| A：机械或合约关系 | 会计恒等式、现金流合同、套利和交割机制 | 固息债券价格与到期收益率反向；临近交割时可交割现货与期货趋于收敛；汇率变动直接改变未套保外币收入折算值 | 最强，但仍受口径、交割品、税费、套保影响 |
| B：经济机制关系 | 变量通过收入、成本、融资、风险溢价影响公司价值 | 铜价影响铜矿企业收入；豆粕价格影响养殖成本；信用利差扩大通常对应风险偏好和融资条件恶化 | 机制清楚，但方向和强度依赖公司暴露与宏观状态 |
| C：经验预测关系 | 历史样本中的领先、滞后或共同波动 | 存款增速与指数、房价与股价、搜索量与收益、船舶数量与矿价 | 最不稳定，容易受趋势、共同因子和数据挖掘影响 |

真正接近“必然”的通常不是“某指标上涨，所以某股票上涨”，而是更窄的约束。例如，在现金流不变时，固息债券收益率上升会使价格下降；临近交割时，期货与合约规定的可交割现货不能长期无成本地大幅背离。股票价格还包含未来现金流、贴现率、风险溢价和市场预期，因此几乎不存在永久固定的单变量相关系数。

#### 相关性不是一条固定电线

股票价格可粗略分解为：

```math
\Delta \log P_t
\approx
\Delta \log \mathrm{E}_t(\mathrm{CF})
-D_t^{\mathrm{equity}}\Delta y_t
-\Delta \mathrm{ERP}_t
+\varepsilon_t.
```

其中：

- $\mathrm{E}_t(\mathrm{CF})$ 是市场对未来现金流的预期；
- $y_t$ 是无风险利率或基准贴现率；
- $D_t^{\mathrm{equity}}$ 是股票对贴现率的敏感度，可类比“权益久期”；
- $\mathrm{ERP}_t$ 是权益风险溢价；
- $\varepsilon_t$ 包含公司特有消息、交易冲击和模型未覆盖部分。

一个外部指标往往同时改变多个项。例如油价上涨：

1. 可能增加石油生产商收入；
2. 也可能抬高全社会成本和通胀预期；
3. 继而影响利率；
4. 还可能是全球需求强劲造成，而不是供给中断造成；
5. 市场可能早已预期这次上涨。

所以“油价与股票负相关”或“油价利好能源股”都缺少条件。原始研究表明，股票对油价冲击的反应取决于油价变化来自供给、全球总需求还是石油特有需求，而不是只取决于油价涨跌。

#### 对你提出的四个猜测先做判断

| 猜测 | 简短结论 | 更值得研究的变量 |
| --- | --- | --- |
| 居民存款与 A 股大盘 | 没有稳定、单向的直接关系；余额水平极易产生伪相关 | 活期与定期结构、同比增量、存款相对 M2、居民风险偏好、基金与 ETF 实际申赎 |
| 房价指数与 A 股大盘 | 有共同信用与财富效应通道，但不同阶段可同涨、背离或反向 | 销售面积和金额、开发投资、新开工、土地、按揭、房企信用利差、银行资产质量 |
| 港口货轮数量与矿价 | “船数”口径过粗，关系可双向且常被船型和拥堵扭曲 | 分货种吞吐量、载重吨、吨海里、吃水、港口库存、排队时长、运价和进口量 |
| 生猪期货与养殖股 | 机制较明确，但不能只看期货价格；股票对应的是未来利润而不是猪价本身 | 猪价减完全成本、饲料成本、能繁母猪、出栏量、死亡率、负债、套保、期限结构 |

后文会逐一展开。

## 2. 合理假设

跨资产研究的第一任务不是寻找最高相关系数，而是明确为什么两个变量应该发生关系。

| 合理假设 | 可证伪含义 | 研究时必须控制的变量 |
| --- | --- | --- |
| 合约和会计恒等式产生的机械关系通常强于经验相关 | 机械关系偏离时，应先检查交割品、期限、税费和套保条件 | 口径、期限、可交割范围 |
| 两个有共同趋势的水平序列可能产生伪相关 | 差分、去趋势或协整检验后关系消失，就不能用水平相关解释 | 趋势、季节性、通胀 |
| 外部变量必须通过收入、成本、融资或风险溢价影响股票 | 找不到中间传导变量时，相关性缺少经济识别 | 行业、公司暴露、宏观状态 |
| 同一行业内公司的净暴露和利润率决定方向与弹性 | 商品上涨时上下游股票同向反应，可能来自共同需求而非成本机制 | 套保、库存、定价权、产品结构 |
| 金融价格可能领先实体数量，也可能反向影响后者 | 只比较同步相关无法判断领先关系 | 发布延迟、交易时钟、反向因果 |

合理假设必须同时给出传导路径、预测方向、时滞范围和失败条件。

## 3. 相关理论与知识

下面先校准关系语言和统计陷阱，再学习利率、信用、汇率、商品、库存、海外市场、行业经营和另类数据。最后把这些变量放进统一的统计路线与交易时钟中。

### 建立正确的“关系”语言

#### 同期相关

样本相关系数为：

```math
\widehat{\rho}_{xy}
=
\frac{\sum_{t=1}^{T}(x_t-\bar{x})(y_t-\bar{y})}
{\sqrt{\sum_{t=1}^{T}(x_t-\bar{x})^2}
\sqrt{\sum_{t=1}^{T}(y_t-\bar{y})^2}}.
```

它只回答“这个样本里是否一起变化”，不回答：

- 谁导致谁；
- 谁先变化；
- 关系是否可交易；
- 关系是否扣除市场、行业和利率后仍存在；
- 下一个样本是否还成立。

#### 领先关系

若指标 $x_t$ 与未来股票收益 $r_{t+h}$ 有关系，研究对象应写成：

```math
\rho_h
=
\mathrm{Corr}(x_t,r_{t+h}).
```

关键是预测时点。在日期 $t$ 形成信号时， $x_t$ 必须真的已经发布。月度数据在月末“所属”，不代表月末就可知；港口、存款、房价和行业统计常在下一月发布。若把数据所属月份误作可知时间，会制造未来函数。

#### 共同驱动，不等于直接传导

许多表面相关来自第三个变量：

```math
z_t \longrightarrow x_t,\qquad
z_t \longrightarrow y_t.
```

例如宽信用可能同时推高房地产交易和股票估值。此时房价与股价相关，不表示房价直接预测股价。反过来，风险偏好下降可能同时增加定期存款、压低股票，并降低住房成交。只做两变量回归会把共同状态误认成直接作用。

#### 关系的方向取决于冲击来源

同样是商品价格上涨，可以来自：

- **需求冲击**：经济强、订单多，商品与周期股可能同涨；
- **供给冲击**：矿山事故、限产、战争，商品涨但下游利润受损；
- **预期冲击**：市场担心未来短缺，价格先动而现货流量尚未变化；
- **金融冲击**：汇率、利率、保证金和风险偏好改变资金持仓。

因此研究应识别“什么冲击推动指标”，不能只把价格变化当成外生变量。

#### 预测周期决定符号

一条关系可能在不同周期相反：

- 分钟到日：资金流、跨市场开盘时差和新闻反应；
- 周到月：库存、订单、分析师修正和政策传导；
- 季度到年：产能、资本开支、信用周期和估值均值回归；
- 多年：人口、技术、制度、产业替代和供给出清。

例如商品涨价短期提高上游利润，但高利润会刺激扩产，几年后可能形成供给过剩。短期趋势与长期均值回归可以同时成立。

#### 最接近“硬关系”的无套利约束

无套利关系比经验相关更稳定，因为明显偏离会允许市场参与者同时买便宜、卖昂贵并锁定收益。但现实交易成本、融资、卖空、交割、限仓和资本管制会形成偏离区间。

在理想化的可储存商品中，期货与现货的持有成本关系可写为：

```math
F_t^{(T)}
=
S_t
\exp\left[
(r_t+c_t-y_t)(T-t)
\right],
```

其中 $r_t$ 是融资成本， $c_t$ 是仓储和保险成本， $y_t$ 是便利收益。现实商品还受质量、地点、运输和交割选择权影响，所以不能只用一个无风险利率计算所有期货“合理价”。

同一标的、同一执行价和到期日的欧式期权，在忽略股息和摩擦时满足看涨看跌平价：

```math
C_t-P_t
=
S_t-K\exp[-r(T-t)].
```

有分红、合约行权方式不同或标的难以融券时要调整。显著偏离首先应检查报价是否同步、合约乘数、股息、交易成本和可执行性，而不是立即认定存在无风险机会。

在货币可自由兑换、融资和远期市场可交易的理想条件下，抛补利率平价约束即期汇率、远期汇率和两地利率：

```math
\frac{F_t^{\mathrm{FX}}}{S_t^{\mathrm{FX}}}
\approx
\frac{1+r_t^{\mathrm{domestic}}\tau}
{1+r_t^{\mathrm{foreign}}\tau}.
```

在岸与离岸、资本流动限制、信用和流动性差异会产生基差。这里的价值是建立基准：先从无套利理论得到“应有关系”，再把偏离解释为真实摩擦，而不是把任意历史相关都称为规律。

### 为什么“两个不断上涨的序列”尤其危险

#### 水平相关很容易是伪相关

居民存款余额、GDP、货币供应量、房价水平和股票指数都可能随时间增长。即使彼此无因果关系，把两个非平稳水平序列回归也可能得到很高的 $R^2$ 和显著系数。

初步应比较以下变换：

```math
\Delta x_t=x_t-x_{t-1},
```

```math
g_t^{(12)}
=
\frac{x_t}{x_{t-12}}-1,
```

```math
\Delta\log x_t
=
\log x_t-\log x_{t-1}.
```

对股价通常使用收益率；对宏观存量通常使用增量、同比增速、占比或相对趋势偏离。季节性强的数据还要同比、季调或加入月份固定效应。

#### 差分不是万能药

如果两个非平稳变量存在稳定的长期均衡组合，直接差分会丢掉长期信息。协整思想是检验某个组合是否平稳：

```math
u_t=y_t-\alpha-\beta x_t.
```

如果 $x_t$ 和 $y_t$ 各自非平稳，但 $u_t$ 平稳，才有理由研究误差修正：

```math
\Delta y_t
=
\lambda u_{t-1}
+\sum_{j=1}^{p}\phi_j\Delta y_{t-j}
+\sum_{j=0}^{q}\theta_j\Delta x_{t-j}
+\varepsilon_t.
```

但“统计上协整”仍不自动等于经济因果或可交易套利。指数成分变化、制度变化和结构突变都可能使长期关系失效。

#### 相关系数本身会随时间变化

用滚动窗口估计：

```math
\widehat{\rho}_{t,w}
=
\mathrm{Corr}
\left(
x_{t-w+1:t},
y_{t-w+1:t}
\right).
```

至少同时画：

- 36 或 60 个月滚动相关；
- 滚动回归系数；
- 置信区间；
- 子样本累计预测误差；
- 关系在牛市、熊市、宽信用、紧信用中的差异。

若只有全样本一个相关系数，结论通常不够。

### 利率、债券与信用：跨资产研究的主骨架

#### 固息债券价格与收益率

固息债券价格为未来现金流折现：

```math
B(y)
=
\sum_{t=1}^{n}
\frac{C_t}{(1+y)^t}
+\frac{M}{(1+y)^n}.
```

在现金流固定时：

```math
\frac{\partial B}{\partial y}<0.
```

小幅收益率变化下：

```math
\frac{\Delta B}{B}
\approx
-D_{\mathrm{mod}}\Delta y
+\frac{1}{2}\mathrm{Convexity}(\Delta y)^2.
```

这是最明确的跨资产关系之一。注意它描述债券自身，不等于“国债收益率上升时所有股票一定下跌”。

#### 利率如何影响股票

利率通过至少四条通道：

1. 折现率：远期现金流权重高的股票通常更敏感；
2. 融资成本：高负债、再融资频繁的公司更敏感；
3. 经济信号：利率上升可能来自增长变强，也可能来自通胀或紧缩；
4. 资产替代：低风险收益率变化影响股票相对吸引力。

因此要分解名义利率：

```math
y_t^{\mathrm{nominal}}
\approx
y_t^{\mathrm{real}}
+\pi_t^{e}
+\mathrm{TermPremium}_t.
```

同样 10 年期收益率上升，若来自真实增长预期改善，周期股现金流可能上修；若来自实际利率或期限溢价急升，高估值长久期股票可能承压。

#### 收益率曲线

常见斜率：

```math
\mathrm{TermSpread}_t
=
y_t^{10\mathrm{Y}}-y_t^{1\mathrm{Y}}.
```

它可能反映未来增长、通胀、政策利率和期限溢价。对银行，“曲线变陡利好净息差”只是粗略起点，因为还要看：

- 存贷款重定价速度；
- 存款成本；
- 信贷需求；
- 贷款结构；
- 不良率与拨备；
- 债券持仓估值；
- 政策对贷款利率的约束。

#### 信用利差

信用利差可写为：

```math
\mathrm{CreditSpread}_{i,t}
=
y_{i,t}^{\mathrm{credit}}
-y_t^{\mathrm{government,matched}}.
```

利差扩大通常包含违约概率、流动性、风险厌恶和供需恶化。它与股票风险常有共同方向：

- 债权人先担心偿债，利差扩大；
- 股东是剩余索取者，尾部风险上升；
- 融资成本上升又会损害未来现金流。

但利差数据要匹配发行人、期限、担保和流动性，不能拿 1 年期低评级债与 10 年期国债直接相减。

#### 适合 A 股的利率信用特征

- 1 年、5 年、10 年国债收益率；
- 政策性金融债与国债利差；
- AAA、AA 等产业债信用利差；
- 民企与国企利差；
- 银行同业存单收益率；
- 回购和货币市场利率；
- 房企、城投和行业债券利差；
- 公司债到期规模与股票市值之比；
- 利率变化与盈利预期变化的联合状态。

中债收益率曲线是较权威的人民币债券利率入口，其编制使用银行间、柜台和交易所等多类报价与成交信息。

### 汇率与股票：先明确报价方向和公司净暴露

#### 不要只说“人民币升值”

必须注明货币对和报价。例如人民币兑美元可写成：

```math
q_t=\mathrm{CNY\ per\ USD}.
```

$q_t$ 上升表示一美元对应更多人民币，即人民币对美元贬值。不同数据源可能使用相反方向，符号不核对会让回归结论完全倒置。

#### 公司净外汇暴露

粗略利润敏感度为：

```math
\frac{\partial \mathrm{Profit}_i}{\partial q}
\approx
\mathrm{ForeignRevenue}_i
-\mathrm{ForeignInputCost}_i
-\mathrm{ForeignDebtService}_i
-\mathrm{HedgeOffset}_i.
```

人民币贬值可能：

- 增加未套保美元收入的人民币折算；
- 抬高进口原材料、设备和能源成本；
- 增加美元债偿付压力；
- 改变海外需求与价格竞争；
- 产生汇兑损益；
- 同时传递资本流动和风险偏好信息。

所以“出口股受益人民币贬值”必须核对收入币种、成本币种、定价权、套保和海外资产负债。

#### 指数层面的汇率关系为何不稳定

汇率既是原因也是结果。增长走弱、利差变化、风险规避、贸易顺差和政策都可推动汇率；这些因素也直接影响股票。应至少控制：

- 中美或境内外利差；
- 美元指数；
- 全球风险偏好；
- 商品价格；
- 中国增长与信用状态；
- 北向和跨境资金；
- 行业权重。

对公司层面，财报披露的境外收入和外币负债比指数回归更有解释力。

### 商品价格与行业股票：用产业利润桥接

#### 上游生产商

在产量暂时固定时：

```math
\Delta \mathrm{EBITDA}
\approx
Q\Delta P
+(P-C)\Delta Q
-Q\Delta C.
```

高经营杠杆使商品小幅涨价可能带来更大利润变化。但需要扣除：

- 品位、地区和产品基差；
- 长协价和定价滞后；
- 特许权使用费和资源税；
- 能源、人工和运输成本；
- 汇率；
- 套保；
- 产量限制和资本开支。

#### 中游加工企业

中游更关心加工价差：

```math
\mathrm{ProcessingMargin}
=
\mathrm{OutputPrice}
-\sum_k a_k\mathrm{InputPrice}_k
-\mathrm{VariableCost}.
```

典型例子：

- 钢铁：钢材价格减铁矿石、焦炭、能源等成本；
- 炼化：成品油和化工品价格减原油及加工成本；
- 火电：上网电价减煤耗成本；
- 养殖：猪价减饲料和完全成本；
- 电池：电芯售价减锂盐、正负极材料等成本；
- 光伏：组件或电池片售价减硅料、辅材和能源成本；
- 造纸：纸价减纸浆、废纸和能源成本。

输出品和投入品同涨时，只看其中一个价格容易把利润方向看反。

#### 典型产业链关系地图

| 外部变量上涨 | 可能受益 | 可能受损 | 必须补充的条件 |
| --- | --- | --- | --- |
| 原油 | 油气开采、部分油服 | 航空、化工下游、运输和耗能行业 | 冲击来源、炼化价差、油价长协、汇率 |
| 煤价 | 煤矿 | 燃煤电厂、水泥和高耗能制造 | 电价机制、长协煤比例、库存 |
| 铁矿石 | 矿山、港口和散运可能受益 | 钢厂成本上升 | 钢材需求、焦炭、钢厂利润、限产 |
| 铜价 | 铜矿和资源持有者 | 电缆、家电等用铜企业可能承压 | 加工费、套保、库存、成本转嫁 |
| 金价 | 黄金矿企通常正暴露 | 黄金消费需求可能受抑 | 实际利率、美元、产量、成本、套保 |
| 锂价 | 低成本锂资源企业 | 电池和整车成本端可能受压 | 库存减值、长协、产品售价、技术路线 |
| 豆粕和玉米 | 种植或贸易相关主体 | 饲料、养猪、养禽成本上升 | 配方替代、库存、套保、终端提价 |
| 电价 | 发电企业收入可能增加 | 高耗能企业成本增加 | 市场化比例、煤价、利用小时、配额 |
| 碳价 | 低排放和配额盈余企业 | 高排放、减排成本高的企业 | 免费配额、核算边界、转嫁能力 |

表中的方向都是条件方向，不是股票买卖口诀。

#### 商品股可能领先商品

股票市场会提前交易：

- 未来产量；
- 供给中断；
- 成本曲线；
- 并购与资源发现；
- 政策和税费；
- 商品远期价格。

若用当天商品涨跌解释当天股票收益，要处理交易时区和信息先后；若用商品价格预测股票，必须检查股票是否已提前反映同一信息。

### 库存、产量和价格：不能脱离库存周期

#### 基本库存恒等式

对一种商品：

```math
\mathrm{Inventory}_t
=
\mathrm{Inventory}_{t-1}
+\mathrm{Production}_t
+\mathrm{Imports}_t
-\mathrm{Consumption}_t
-\mathrm{Exports}_t
+\mathrm{Adjustment}_t.
```

库存下降不一定利多：

- 可能是需求强导致主动去库；
- 也可能是企业悲观、减少采购导致被动去库；
- 统计口径可能只覆盖部分仓库；
- 隐性库存可能转移；
- 价格已提前反映去库。

要同时看价格、库存变化和产量：

| 状态 | 可能解释 |
| --- | --- |
| 价格涨、库存降 | 需求强或供给紧，通常偏强 |
| 价格涨、库存涨 | 预期强、囤货或供给释放，后续需辨别 |
| 价格跌、库存涨 | 需求弱或供给过剩，通常偏弱 |
| 价格跌、库存降 | 主动清库存、供给收缩或需求仍弱 |

#### 库存的可比性

交易所仓单、港口库存、钢厂库存、社会库存和企业财报库存不是同一个集合。研究前记录：

- 覆盖地点和样本；
- 实物吨数还是货值；
- 是否可交割；
- 品种和质量；
- 更新频率；
- 历史口径变更；
- 是否会回溯修订。

### 海外市场、港股与 A 股

#### 同一公司并不等于同一证券

A/H 两地上市公司共享公司现金流，但证券价格还受：

- 币种；
- 投资者结构；
- 做空和衍生品条件；
- 交易时间；
- 资本流动限制；
- 股息税和交易成本；
- 指数纳入；
- 流动性和风险偏好；

影响。A/H 价差可以长期存在，不能把价差当成无风险套利。

#### 海外指数如何传导到 A 股

常见通道包括：

- 隔夜全球风险偏好；
- 美元、利率和大宗商品；
- 同行业估值锚；
- 海外上市中国公司；
- 跨境资金；
- 共同宏观新闻；
- 时区导致的价格发现先后。

隔夜美股下跌与次日 A 股低开可能有统计关系，但收盘收益还受中国本地信息影响。研究应分开：

```math
r_t^{\mathrm{A,open}}
=
\log O_t-\log C_{t-1},
```

```math
r_t^{\mathrm{A,intraday}}
=
\log C_t-\log O_t.
```

海外信息更可能进入隔夜跳空，而不一定预测 A 股开盘后的日内方向。

#### 商品和海外同行可作“信息代理”

当 A 股休市而海外相关资产仍交易时，海外矿业股、商品期货、港股或 ADR 可能先吸收新闻。但要注意：

- 标的业务不完全一致；
- 海外资产自身有本地因子；
- 汇率与时区不同；
- 节假日信息累计；
- A 股涨跌停会延迟价格发现。

可使用事件窗口和市场、行业中性收益，而不是简单复制隔夜涨跌。

#### ETF 申赎、融资余额和期权指标

这些变量比居民存款更贴近证券市场，但仍不能直接当作未来涨跌方向。

**ETF 份额与净申赎**

ETF 份额增加表示一级市场出现净申购，但动机可能是：

- 长期配置；
- 短期交易；
- 套利和做市；
- 衍生品对冲；
- 指数调整；
- 价格大跌后的逆向申购。

标准化流量可写为：

```math
\mathrm{ETFFlow}_{t}
=
\frac{\Delta\mathrm{Shares}_{t}
\times\mathrm{NAV}_{t-1}}
{\mathrm{AUM}_{t-1}}.
```

应分别研究流量之前、当日和之后的收益。大涨吸引申购与申购推动价格是两种相反时间顺序。

**融资余额**

融资余额上升可能代表杠杆风险偏好增强，也可能只是股价上涨后抵押物价值和融资需求同步增加。更合理的特征包括融资买入额占成交额、融资余额变化、偿还额、个股可融资范围和制度变化。融资余额是持仓存量，不是当天净买入额。

**期权隐含波动率**

隐含波动率是把期权市场价格代回定价模型得到的参数。它融合了风险中性分布、尾部保险需求、供需和波动风险溢价，不是未来实现波动率的无偏点预测。可以比较：

```math
\mathrm{VRP}_t
=
\mathrm{IV}_t^2
-\mathrm{E}_t^{\mathrm{stat}}
\left(
\mathrm{RV}_{t\rightarrow T}^2
\right),
```

其中 $\mathrm{IV}$ 是隐含波动率， $\mathrm{RV}$ 是未来实现波动率，二者差异可理解为模型和风险溢价的混合。

认沽与认购成交量比、偏度和波动率期限结构可以反映保护需求或拥挤，但成交量比高既可能是看空投机，也可能是已有多头在买保险。应结合持仓变化、买卖方向、执行价和到期日。

### 行业经营数据：往往比宽泛宏观指标更接近公司利润

#### 指标应尽量靠近收入与成本

从弱到强可以这样理解：

```math
\text{宏观总量}
\rightarrow
\text{行业活动}
\rightarrow
\text{公司经营}
\rightarrow
\text{财务结果}.
```

越靠近公司，经济解释越直接，但数据覆盖可能越窄、噪声和选择偏差也可能更大。

#### 行业指标示例

| 行业 | 股票外指标 | 主要映射 | 常见陷阱 |
| --- | --- | --- | --- |
| 银行 | 社融、贷款、存款结构、利率、信用利差、不良生成 | 规模、净息差、资产质量 | 宽信用同时可能伴随让利和风险下沉 |
| 券商 | 市场成交额、两融、IPO 和再融资、基金发行 | 经纪、利息、投行、资管、自营 | 成交额高不保证自营盈利 |
| 保险 | 长端利率、信用利差、权益市场、保费和新业务价值 | 投资收益和负债价值 | 利率上升同时带来估值损失与再投资收益 |
| 地产 | 销售、土地、按揭、竣工、房企债利差 | 回款、收入、信用和产业链 | 房价最平稳，可能不是最领先 |
| 汽车 | 批发、零售、上险、库存、折扣、出口 | 销量、价格和渠道库存 | 批发压库不等于终端需求 |
| 家电 | 地产竣工、零售、出口、铜铝塑料价格 | 销量和成本 | 出货与终端销售错位 |
| 航空 | 客座率、票价、油价、汇率、运力 | 收入和燃油成本 | 客座率高但票价低也可能亏损 |
| 航运 | 即期运价、长协、港口量、运力交付、燃油 | 运价、装载率和成本 | 指数与公司航线、合同不匹配 |
| 半导体 | 全球销售、库存天数、设备订单、晶圆价格 | 周期和资本开支 | 技术代际和产品结构差异巨大 |
| 光伏 | 硅料、硅片、电池片、组件价、排产和库存 | 各环节价差和出货 | “装机增长”可与全链亏损并存 |
| 电力 | 发电量、利用小时、电价、煤价、水情 | 收入和燃料成本 | 水火核新能源模式不能混合 |
| 旅游酒店 | 客流、入住率、平均房价、航班、节假日 | 量价与经营杠杆 | 同比受基数和节假日错位影响 |
| 传媒影视 | 票房、广告、用户、版号和内容排期 | 收入与项目成功率 | 单一爆款不可线性外推 |

#### 最值得构造的是“公司暴露加权指标”

行业总量对每家公司含义不同。可以写成：

```math
X_{i,t}^{\mathrm{exposure}}
=
\sum_k w_{i,k,t}X_{k,t},
```

其中 $w_{i,k,t}$ 可来自地区、产品、客户、币种、航线、发电类型或原料结构。权重也必须是当时可知的，不能用今天业务结构回填过去。

### 另类数据：更快不等于更真

#### 常见类型

- 船舶 AIS 和港口拥堵；
- 卫星夜光、停车场、矿山和储罐影像；
- 搜索指数和新闻热度；
- App 下载、活跃用户和网页流量；
- 招聘职位；
- 电商价格、销量和评价；
- 支付、发票和物流；
- 航班、酒店和景区客流；
- 工厂用电、排放和设备开工；
- 门店位置和开闭店。

#### 另类数据的五类偏差

1. **覆盖偏差**：只覆盖特定平台、地区或设备；
2. **样本漂移**：平台份额和用户结构变化；
3. **算法漂移**：供应商修改清洗、识别或补全算法；
4. **幸存者偏差**：历史只保留今天仍覆盖的企业；
5. **回填偏差**：供应商事后修正历史，但回测误当实时可知。

此外还有法律、隐私、授权和非公开重大信息风险。免费获得并不等于可以合法用于交易或再分发。

#### 如何验证一个另类指标

先不要预测收益，先验证它是否测到了声称的经济量：

1. 与官方低频数据做同期和领先比较；
2. 检查节假日、天气、设备中断；
3. 抽样人工核验；
4. 记录供应商版本；
5. 分公司和分时间检查覆盖率；
6. 检查修订前后差异；
7. 证明它对公司收入、成本或产量有增量解释；
8. 最后才检验市场是否尚未计价。

“预测官方数据”与“预测股票收益”是两道不同关卡。

### 从相关到可交易信号的统计路线

#### 第一步：先画机制图

在跑回归前写清：

```math
\text{外部指标}
\rightarrow
\text{公司收入、成本、资产负债或贴现率}
\rightarrow
\text{盈利预期}
\rightarrow
\text{股票价格}.
```

同时列出共同因子、反向因果和市场提前计价路径。没有可辩护机制的相关，优先视为探索结果。

#### 第二步：确定目标变量

区分三个目标：

1. 预测行业基本面；
2. 预测分析师盈利修正；
3. 预测股票异常收益。

外部指标能很好预测盈利，不代表能预测收益，因为价格可能更早反映。建议逐级检验：

```math
X_t\rightarrow \Delta\mathrm{Fundamental}_{t+h},
```

```math
X_t\rightarrow \Delta\mathrm{Expectation}_{t+h},
```

```math
X_t\rightarrow r_{t+h}^{\mathrm{abnormal}}.
```

#### 第三步：对齐可知时间

每条数据至少保存：

| 字段 | 含义 |
| --- | --- |
| period_end | 数据描述的经济期间 |
| release_time | 首次公开时间 |
| ingest_time | 研究系统首次取得时间 |
| revision_time | 修订时间 |
| source_version | 来源和版本 |
| value_first | 首次公布值 |
| value_latest | 最新修订值 |

回测只能使用当时的 value_first 或当时版本。网站现在显示的完整历史可能包含修订。

#### 第四步：构造意外而不只是数值

市场反应更接近：

```math
\mathrm{Surprise}_t
=
\frac{\mathrm{Actual}_t-\mathrm{Expected}_{t^-}}
{\widehat{\sigma}_{\mathrm{surprise}}}.
```

若没有一致预期，可用：

- 历史实时预测模型；
- 公布前可获得的高频代理；
- 季节性基线；
- 调查预期；
- 期货或利率隐含预期。

不能用事后最终数据训练预测，再把其残差当成历史“意外”。

#### 第五步：控制共同因子

行业或股票回归可写为：

```math
r_{i,t+h}
=
\alpha
+\beta X_t
+\gamma^\top F_t
+\delta^\top Z_{i,t}
+\varepsilon_{i,t+h},
```

其中 $F_t$ 可含市场、利率、信用、汇率、商品和风险偏好， $Z_{i,t}$ 可含规模、价值、动量、行业与流动性。 $\beta$ 在控制后消失，说明原相关可能只是公共暴露。

#### 第六步：检验领先滞后

分布滞后模型：

```math
r_{t+h}
=
\alpha
+\sum_{j=0}^{p}\beta_j X_{t-j}
+\sum_{k=1}^{q}\phi_k r_{t-k}
+\gamma^\top F_t
+\varepsilon_{t+h}.
```

不要遍历大量滞后后只报告最显著的一个。应预先规定窗口，或对全部尝试做多重检验校正。

#### Granger 因果不是经济因果

如果加入 $x$ 的滞后后，能提高对 $y$ 的预测，可称 $x$ 在给定信息集下 Granger 预测 $y$ 。这只说明时间先后和增量预测，不排除：

- 遗漏共同变量；
- 测量频率差异；
- 另一个更快市场先反应；
- 结构变化；
- 数据挖掘。

文档和报告应写“Granger 预测关系”，不要直接写“证明了因果”。

#### 状态依赖

允许系数随状态变化：

```math
r_{t+h}
=
\alpha
+\beta_0X_t
+\beta_1X_t I(S_t=\mathrm{tight})
+\gamma^\top F_t
+\varepsilon_{t+h}.
```

状态可来自信用宽紧、库存高低、产能利用率、牛熊、波动率和政策阶段。状态必须只用当时信息定义，不能事后看完整周期标注。

#### 非线性

现实关系可能有阈值：

- 油价温和上涨可由需求强驱动，暴涨则损害下游；
- 信用利差小幅变化无关紧要，越过再融资阈值后风险突变；
- 库存处于极低分位时，供给冲击价格弹性更大；
- 高杠杆公司对房价下跌比上涨更敏感。

可以使用样条、树模型或分位数回归，但先用透明分组证明非线性存在，再上复杂模型。

#### 多重检验

若测试 $m$ 个彼此无效的指标，每个按 5% 显著性判断，预期也会出现约：

```math
0.05m
```

个“显著”结果。测试上百种港口、商品、滞后和行业组合时，偶然发现几条漂亮曲线是必然事件。

至少使用：

- 预注册或冻结研究假设；
- train、validation、test 时间切分；
- false discovery rate；
- 更严格的统计阈值；
- 经济机制筛选；
- 真正样本外和纸面交易；
- 报告所有尝试，不只报告成功项。

#### 样本外评价

对每个特征比较：

1. 历史均值基线；
2. 只含市场状态的基线；
3. 加入外部指标的模型；
4. 扣成本后的策略结果。

样本外预测 $R^2$ 可写为：

```math
R_{\mathrm{OOS}}^2
=
1-
\frac{\sum_t(y_t-\widehat{y}_t)^2}
{\sum_t(y_t-\widehat{y}_t^{\mathrm{benchmark}})^2}.
```

$R_{\mathrm{OOS}}^2<0$ 表示还不如基线。金融预测中样本内显著、样本外失败很常见，应把失败当作正常研究结果。

### 数据频率与交易时钟

#### 低频数据不能凭空变成日频

把月度存款值向前填充到每个交易日，不会创造日频信息，只会重复同一个状态。标准误若按日频样本数计算，会被严重低估。

可选方法：

- 以月频研究月度收益；
- 只在发布日期更新信号；
- 使用混频模型；
- 将高频代理用于 nowcast，但保留真实发布日期；
- 标准误按时间聚类或使用适合重叠收益的修正。

#### 交易时区和休市

跨市场研究要区分：

- 信息在北京时间何时发生；
- A 股当时是否开盘；
- 海外资产的收益窗口是否包含同一条信息；
- 周末和节假日累计信息；
- 夏令时；
- 期货夜盘归属哪个交易日。

简单按自然日期 join 很容易把未来市场收益配给过去。

#### 重叠收益

若每天预测未来 20 日收益，目标区间高度重叠，残差会序列相关。显著性需要使用 Newey-West 等稳健标准误、非重叠抽样或适当的时间序列 bootstrap。

## 4. 典型案例

四个案例分别代表资金配置、财富与信用周期、全球实体物流和产业利润。每个案例都从直觉猜想出发，再展示为什么真实关系比一句“正相关”复杂。

| 案例 | 初始猜想 | 更可研究的对象 |
| --- | --- | --- |
| 居民存款与 A 股 | 存款会流入股市 | 存款结构、机会成本、风险偏好与增量资金 |
| 房价与 A 股 | 房价涨跌映射大盘 | 信用周期、财富效应、地产链盈利和资产替代 |
| 港口船舶与矿产 | 船越多，矿价越高 | 运量、运距、港口库存、运价与供需冲击 |
| 生猪期货与养殖股 | 猪价上涨，养殖股上涨 | 养殖利润差、成本、出栏、套保和周期位置 |

案例之后给出统一研究假设模板，便于把新的生活观察转成正式项目。

### 居民存款与 A 股：不是“蓄水池一开闸”

#### 居民存款是什么

人民银行金融机构人民币信贷收支表将住户存款拆为：

```math
\mathrm{Household\ Deposits}
=
\mathrm{Demand\ Deposits}
+\mathrm{Time\ and\ Other\ Deposits}.
```

存款余额上升可能来自：

- 居民收入和工资增加；
- 银行贷款派生存款；
- 财政向居民或企业支出后资金转入；
- 房地产、理财、基金或股票卖出后回到银行；
- 风险偏好下降和预防性储蓄；
- 定期存款利率相对其他资产更有吸引力；
- 季节性工资、奖金、税费和节假日因素；
- 统计口径或机构范围变化。

因此存款不是一笔专门等待买股票的资金。

#### 为什么“存款多，大盘就涨”不成立

股票交易中，买方支付的资金通常进入卖方账户。除新股发行、税费、跨境流动等情况外，买股票并不会让全社会银行存款凭空消失，只是存款在主体之间转移。股票价格由边际成交决定，不要求所有存款“搬家”。

同时：

- 存款增加可能意味着收入改善，间接利好盈利；
- 也可能意味着风险厌恶上升，居民减少风险资产配置；
- 定期化上升可能意味着资金锁定意愿更强；
- 贷款扩张可同时创造存款和推高资产价格；
- 股市上涨后居民卖出获利，也可能让存款随后增加。

方向既可能正、负，也可能由第三个变量共同驱动。

#### 更合理的研究变量

不要直接回归“住户存款余额水平对上证指数水平”。可以构造：

1. 住户存款 12 个月增量；
2. 活期存款同比与定期存款同比之差；
3. 定期存款占住户存款比例；
4. 住户存款相对 M2 或居民可支配收入；
5. 存款增速相对其长期趋势的偏离；
6. 住户存款与住户贷款的净变化；
7. 基金、ETF、融资余额和新开户等实际证券市场流量；
8. 银行理财、货币基金、债券基金与权益基金之间的份额变化。

一个可检验模型是：

```math
r_{t\rightarrow t+h}^{\mathrm{index}}
=
\alpha
+\beta_1\mathrm{DepositShift}_t
+\beta_2\mathrm{Credit}_t
+\beta_3\mathrm{Rate}_t
+\beta_4\mathrm{Valuation}_t
+\beta_5\mathrm{Trend}_t
+\varepsilon_{t+h}.
```

必须做滚动样本外检验。大概率结果是系数不稳定、单变量解释力很低；这本身就是有价值的结论。

#### 如何解释“存款搬家”

把它改写成一组可观测命题：

- 活期化是否上升？
- 权益基金和股票 ETF 是否出现净申购？
- 券商客户保证金或非银存款是否变化？
- 市场成交额和换手率是否同步上升？
- 低风险产品收益率是否下降？
- 新增资金来自已有存款重配，还是杠杆和信用扩张？
- 这些变化发生在价格上涨之前还是之后？

只有流量、价格和时间顺序同时支持，才能谨慎称为风险资产重配；不能仅凭存款余额下降下结论。

### 房价与 A 股：共享信用周期，但不是镜像

#### 可能的正向共同关系

房价和股票可能共同受以下变量推动：

```math
\text{宽松融资}
\rightarrow
\begin{cases}
\text{住房需求、抵押品价值和地产信用上升},\\
\text{股票贴现率或风险溢价下降}.
\end{cases}
```

房价上涨还可能通过：

- 居民财富感受和消费；
- 抵押品价值与借款能力；
- 地方土地收入和财政支出；
- 房地产开发、建材、家居和金融产业链；
- 银行抵押贷款质量；

影响上市公司现金流和风险。

#### 为什么也会背离

房产与股票是竞争性的资产配置选择，房地产收紧或收益预期下降时，部分资金可能转向金融资产；反过来，房市繁荣也可能吸收居民首付和杠杆能力。更重要的是：

- 股票是对未来的连续定价，常领先实体数据；
- 房价指数月频、成交稀疏、质量调整复杂，波动被平滑；
- 城市差异巨大，全国平均会掩盖结构；
- A 股指数行业权重与房地产经济权重不同；
- 地产压力可能利空银行和建材，却利好政策宽松预期；
- 政策可能同时托底住房、限制投机并支持股票市场。

所以没有固定的“房价涨则股价涨”或“跷跷板”公式。

#### 房价指数不是房地产周期的完整代理

国家统计局 70 个大中城市住宅价格指数提供新房、二手房的环比和同比，但研究地产对股票的影响还应加入：

| 维度 | 指标 | 主要含义 |
| --- | --- | --- |
| 需求 | 销售面积、销售额、套数、去化周期 | 成交是否真实改善 |
| 价格 | 新房和二手房环比、同比、城市分布 | 价格状态，通常较平滑 |
| 供给 | 新开工、施工、竣工、待售面积 | 未来供给与产业链工作量 |
| 投资 | 房地产开发投资、土地购置 | 对固定资产投资和上游需求 |
| 融资 | 按揭、开发贷、境内外债券利差 | 购房能力与房企生存条件 |
| 信用风险 | 违约、展期、逾期、银行不良 | 尾部损失和金融传染 |
| 财政 | 土地出让收入、地方专项债 | 地方财政与项目能力 |

对银行股，抵押物价值和资产质量可能比全国房价同比更重要；对建材和家居，销售、竣工和回款可能更直接；对房企股票，信用利差、债务到期和可售货值往往比平均房价更重要。

#### 一个更科学的研究设计

可将城市房价和公司地域暴露结合：

```math
\mathrm{HousingExposure}_{i,t}
=
\sum_c w_{i,c,t}\Delta \log H_{c,t},
```

其中 $w_{i,c,t}$ 是公司在城市 $c$ 的销售、土地储备、门店、贷款或收入暴露。然后在公司和月份固定效应下检验：

```math
r_{i,t+1}
=
\alpha_i+\delta_t
+\beta\mathrm{HousingExposure}_{i,t}
+\gamma^\top X_{i,t}
+\varepsilon_{i,t+1}.
```

这比拿全国房价指数与上证指数做一条相关线更接近经济机制。

### 港口、船舶与矿产价格：数量、运距、库存和价格互相反馈

#### 为什么“港口货轮数量”通常不科学

同样 10 艘船，可能是 10 艘小型散货船，也可能是 10 艘超大型矿砂船。原始船数忽略：

- 船型与载重吨；
- 实际装载率和吃水；
- 货种；
- 航线和航程；
- 空载还是重载；
- 到港、靠泊、离港还是锚地排队；
- 港口效率和天气；
- 拥堵导致的重复计数；
- AIS 关闭、漂移和覆盖缺失。

比船数更合理的是：

```math
\mathrm{CargoFlow}_t
\approx
\sum_{v\in\mathcal{V}_t}
\mathrm{DWT}_v
\times\mathrm{LoadFactor}_{v,t}
\times\mathrm{CargoProbability}_{v,t}.
```

若研究全球运输需求，还可以用吨海里：

```math
\mathrm{TonMiles}_t
=
\sum_v
\mathrm{CargoTons}_{v,t}
\times
\mathrm{Distance}_{v,t}.
```

相同吨数从更远来源运输，会占用更多船舶运力并推高运价。

#### 价格可能领先货流

矿价是预期变量。市场预期未来基建刺激或矿山减产时，期货和现货价格可能先涨；采购、装船、航行、到港和统计发布要晚数周。因此观察到：

```math
\mathrm{Price}_{t}
\longrightarrow
\mathrm{Shipment}_{t+1:t+k}
```

不表示价格“导致”真实需求，可能只是价格比物理流量更早反映同一个信息。

反过来，突发到港下降、港口库存去化或拥堵也可能向市场提供供给信息，引起价格变化。因果可以双向。

#### 建议的矿产供需看板

以铁矿石为例，至少同时跟踪：

| 环节 | 指标 | 解释 |
| --- | --- | --- |
| 海外供给 | 主要矿山发运量、港口离港量、天气和检修 | 上游可供货量 |
| 海运 | 船型运价、吨海里、航速、拥堵 | 运输成本和可用运力 |
| 中国进口 | 海关进口量、来源国、均价 | 已进入国境的数量和价值 |
| 港口 | 分货种吞吐、到港、疏港、库存、品位结构 | 近端供需与可用库存 |
| 钢厂 | 高炉开工、铁水产量、原料库存 | 实际消耗 |
| 成材 | 钢材产量、表观消费、社会库存、价格 | 下游需求 |
| 利润 | 螺纹或热卷价格减铁矿、焦炭等成本 | 钢厂生产激励 |
| 金融 | 现货、期货、基差、月差、持仓 | 预期与资金状态 |

研究铜、煤、原油、铝、锂时也应沿“资源供给—运输—库存—加工—终端需求—利润”建立链条，而不是寻找一个神奇领先指标。

#### 运价与航运股也不是一一对应

航运指数必须匹配业务：

- 集装箱：SCFI、CCFI 等；
- 干散货：铁矿石、煤、粮食相关船型运价；
- 油轮：原油轮与成品油轮；
- 内贸与外贸、即期与长协也不同。

航运公司利润还取决于：

```math
\mathrm{Profit}
\approx
(\mathrm{FreightRate}-\mathrm{VoyageCost})
\times\mathrm{EffectiveCapacity}
-\mathrm{FixedCost}
-\mathrm{FinanceCost}.
```

若公司大量运力签了低价长协，即期运价暴涨未必立即进入利润；若公司租入船舶，租金也可能同步上涨。要看自有与租入运力、合同期限、航线暴露、燃油成本、汇率和新船交付。

### 生猪期货与养殖股：应研究利润差，不只研究猪价

#### 期货价格是什么

生猪期货是标准化合约。大商所业务细则规定其采用实物交割，并规定交割质量、地点与升贴水。某月合约价格代表符合合约条件的生猪在对应交割时空下的市场价格，不等于“全国未来平均猪价的无误预测”。

基差可以定义为：

```math
b_t^{(T)}
=S_t-F_t^{(T)},
```

其中 $S_t$ 是与交割品尽量可比的现货价， $F_t^{(T)}$ 是到期日为 $T$ 的期货价。临近到期通常应收敛，但运输、地区、质量、交割成本、限仓和市场拥挤会造成偏差。

期限结构：

```math
\mathrm{Slope}_t
=
F_t^{(T_2)}-F_t^{(T_1)},\qquad T_2>T_1,
```

反映不同月份供需预期与风险补偿，不能简单翻译成未来现货涨跌。

#### 养殖公司的核心是单位利润

更接近公司经营的式子是：

```math
\mathrm{UnitMargin}_{i,t}
=
\mathrm{HogPrice}_{i,t}
-\mathrm{FullCost}_{i,t}.
```

完全成本包含：

- 玉米、豆粕等饲料；
- 仔猪或种猪成本；
- 疫苗、兽药和生物安全；
- 死亡率和料肉比；
- 人工、能源和运输；
- 折旧；
- 财务费用；
- 总部及管理费用。

公司利润可粗略写成：

```math
\mathrm{Profit}_{i,t}
\approx
\mathrm{UnitMargin}_{i,t}
\times\mathrm{SalesVolume}_{i,t}
+\mathrm{OtherBusiness}_{i,t}
+\mathrm{HedgePnL}_{i,t}.
```

猪价相同，成本、出栏和负债不同的公司，利润弹性完全不同。

#### 产能周期为何重要

农业农村部将能繁母猪存栏作为生猪产能调控的核心指标，并概括为“长期调母猪，短期调肥猪”。传导大致是：

```math
\text{能繁母猪}
\rightarrow
\text{仔猪}
\rightarrow
\text{育肥猪}
\rightarrow
\text{未来出栏供给}.
```

中间存在生物学时滞、生产效率、疫情、二次育肥和压栏等扰动。能繁母猪增加通常意味着较远期供给压力，但不能机械设定固定几个月，因为生产效率和行为会变。

#### 股价、期货和现货谁领先？

三者都在处理预期：

- 股票反映公司多年现金流、资产负债表和风险溢价；
- 期货反映特定交割月份的商品价格；
- 现货反映当前地区和规格的成交；
- 行业产能数据较慢但影响更长。

股票可能在猪价仍低时上涨，因为市场预期去产能和未来利润修复；也可能在猪价高位下跌，因为市场预期补栏后供给增加。所谓“猪价涨，养殖股涨”只在盈利修正超过已计价幅度时成立。

#### 一个可执行的养殖研究框架

构造以下特征：

1. 现货猪价的地区加权均值；
2. 近月和远月期货收益；
3. 基差与跨期价差；
4. 玉米和豆粕成本篮子；
5. 模拟养殖利润；
6. 能繁母猪和仔猪价格；
7. 公司月度出栏、售价和完全成本；
8. 公司资产负债率、现金和短期债务；
9. 套保规模与会计处理；
10. 股票此前收益、估值和拥挤度。

然后分别预测未来盈利修正与未来股票异常收益。若直接从猪价预测股票收益，会混淆经营信息和市场已计价信息。

### 一份研究假设模板

看到“指标 X 与股票 Y 有关系”时，先填写：

1. **经济主体**：谁生产、消费、借贷、投资或承担风险？
2. **指标定义**：水平、流量、价格、价差、库存还是预期？
3. **单位口径**：名义还是实际，吨还是金额，现货还是期货？
4. **传导机制**：影响收入、成本、资产负债、贴现率还是风险溢价？
5. **公司暴露**：哪部分业务、地区、币种和合约真正相关？
6. **冲击来源**：供给、需求、政策、预期还是金融条件？
7. **方向条件**：在什么条件下正，在什么条件下负？
8. **时间顺序**：数据描述何时、何时首次发布、何时可交易？
9. **共同因子**：还有什么变量同时推动 X 和 Y？
10. **反向因果**：股票或商品价格会不会反过来影响 X？
11. **预测目标**：基本面、预期修正还是异常收益？
12. **预测周期**：日、月、季度还是年度？
13. **基线模型**：不加 X 时最简单的预测是什么？
14. **稳定性**：滚动窗口、子样本和制度变化如何检查？
15. **成本约束**：信号频率、容量、滑点和 T+1 如何处理？
16. **证伪条件**：什么结果会让你放弃这个假设？

写不清前八项时，不要急着训练模型。

### 初学者应记住的二十五句话

1. 真正固定的关系多来自合同、会计或套利，不来自一句市场俗语。
2. 股票反映未来利润与贴现率，不是当前实体指标的同步仪表盘。
3. 两个长期上涨的水平序列很容易产生伪相关。
4. 居民存款不是等待入市的专用资金池。
5. 买卖股票主要改变存款所有者，不机械消灭全社会存款。
6. 房价和股价可以共享信用周期，也可以因资产替代和政策而背离。
7. 房地产销售、信用和开工通常比平均房价更贴近产业链现金流。
8. 船数不等于货量，货量不等于吨海里。
9. 价格常先于装船、运输、到港和统计发布。
10. 期货价格不是未来现货的无误预言。
11. 临近交割的收敛约束只适用于合约规定的可比现货。
12. 养殖股对应猪价减完全成本后的利润，不只对应猪价。
13. 商品涨价对上游是收入，对下游可能是成本。
14. 中游企业应研究产品与原料的价差。
15. 库存下降既可能是需求强，也可能是企业停止补库。
16. 国债收益率上升使固息债券价格下降，但不保证所有股票下跌。
17. 利率变化的原因比利率变化本身更重要。
18. 信用利差常比无风险利率更直接反映高杠杆公司的压力。
19. 汇率方向必须先写清报价单位。
20. 公司净外汇暴露比“出口行业”标签更可靠。
21. Granger 因果是增量预测，不是结构因果。
22. 外部指标预测基本面，不代表它还能预测已交易的股价。
23. 低频数据向前填充不会创造高频信息。
24. 研究上百种关系却只展示最显著的一种，几乎必然过拟合。
25. 一个稳定的弱关系通常比一个解释不了的高相关更有研究价值。

## 5. 练习

实践项目需要交付完整的研究记录。最低验收标准如下：

1. 为股票和外部变量分别记录经济含义、单位、频率、发布日期和修订规则；
2. 先画原始序列，再检查差分、同比、去趋势和可能的协整关系；
3. 同时检验同步、领先和滞后关系，但对多重检验做校正；
4. 用行业或公司暴露验证传导机制，而不是只报告全样本相关系数；
5. 使用滚动窗口和样本外区间，报告关系在不同宏观状态下是否稳定；
6. 最终结论必须区分解释关系、预测关系和可交易关系。

### 适合初学者的六个实践项目

#### 练习 1：推翻或验证“居民存款预测大盘”

**目标**：学习非平稳、发布日期和样本外。

步骤：

1. 下载人民银行住户活期、定期和总存款月度数据；
2. 保存每期首次发布日期；
3. 下载宽基指数月度总收益；
4. 比较水平、同比、12 个月增量、定期占比；
5. 做 ADF 或其他单位根诊断；
6. 加入社融、利率、估值和趋势控制；
7. 滚动估计 60 个月窗口；
8. 预测未来 1、3、6 个月；
9. 保留最后若干年为纯样本外；
10. 报告系数稳定性和 $R_{\mathrm{OOS}}^2$ 。

预期学习结果不是得到正相关或负相关，而是理解为什么原始水平相关不可信。

#### 练习 2：房价与地产产业链

**目标**：比较一个平滑价格指标和更直接的经营指标。

同时使用：

- 70 城房价；
- 商品房销售面积和金额；
- 新开工、竣工和开发投资；
- 房地产贷款或按揭；
- 房企信用利差；
- 地产、银行、建材和家居行业收益。

检验哪个指标先解释盈利修正，哪个只与同期市场状态共变。按 2015 年前后、疫情前后、地产信用冲击前后分样本，不要假定全历史同一系数。

#### 练习 3：铁矿石的物理流量与价格

**目标**：理解预期价格与滞后物理数据。

构造：

- 铁矿石期现收益和基差；
- 海关进口量；
- 港口库存；
- 港口分货种吞吐；
- 高炉开工或铁水；
- 钢材库存和价格；
- 钢厂模拟利润；
- 矿业、钢铁、港口和干散货航运行业收益。

画完整的交叉相关函数，但预先规定最大滞后。比较“矿价预测货流”和“货流意外预测矿价”，控制全球增长和汇率。

#### 练习 4：生猪利润周期

**目标**：从单一商品价升级到公司利润。

比较四类模型：

1. 只用生猪现货；
2. 只用生猪期货；
3. 用猪价减饲料篮子；
4. 加入产能、公司成本、出栏和负债。

分别预测公司季度毛利率、盈利预测修正和股票异常收益。你很可能发现，对基本面预测有效的变量，对股票收益未必有效。

#### 练习 5：利率变化与成长、价值

**目标**：理解冲击来源和状态依赖。

使用 1 年与 10 年国债收益率，构造水平与斜率变化，比较高估值成长和低估值价值组合。再加入增长、通胀和信用状态交互项。不要用“利率升则成长跌”作为未经检验的永久规则。

#### 练习 6：一个真正的另类数据审计

**目标**：先验证数据产品，再研究证券。

选择 AIS、搜索或门店数据：

1. 保存原始快照和版本；
2. 统计覆盖率；
3. 检查缺失和历史回填；
4. 与官方数据交叉验证；
5. 识别节假日和结构变化；
6. 证明对经营数据有增量解释；
7. 再检验股票收益；
8. 留出完整样本外；
9. 记录数据费用、授权和可持续性。

#### 统计方法与跨资产研究

- Granger, C. W. J. (1969), [Investigating Causal Relations by Econometric Models and Cross-spectral Methods](https://doi.org/10.2307/1912791)：预测意义上的 Granger 因果起点。

- Claessens, S. and Kose, M. A. (2017), [Asset Prices and Macroeconomic Outcomes: A Survey](https://www.bis.org/publ/work676.htm)：股票、房价、汇率、利率与实体经济传导的系统综述。

阅读顺序建议：先用官方口径把变量定义正确，再读协整和 Granger；之后读样本外预测与多重检验；最后研究具体产业冲击。不要从相关热力图直接跳到交易策略。
