# Lesson 0：金融与市场背景课

Lesson 0 面向数学、机器学习基础较强，但金融知识尚未系统化的学习者。四课统一采用以下结构：

1. **问题导入**：从日常投资困惑进入，不先背结论；
2. **合理假设**：把直觉改写成可证伪命题，并说明控制变量；
3. **相关理论与知识**：建立概念、公式、数据口径和因果机制；
4. **典型案例**：观察理论在行业、事件和数据研究中怎样使用；
5. **练习**：形成可复核的研究产物，而不是只做阅读理解。

## 推荐顺序

### 0.1 财务、行业与估值基础

[开始学习](01-financial-fundamentals.md)

先理解公司怎样赚钱、报表怎样记录、估值为什么必须区分行业与周期。完成后应能识别低 PE 陷阱，并把财务字段按实际公告时间转成量化因子。

### 0.2 行情、成交、盘口与技术指标

[开始学习](02-market-indicators.md)

从真实成交和 A 股交易制度出发，理解价格、成交量、换手率、盘口、流动性、筹码与技术指标。完成后应能独立验证双均线等基础信号，并正确处理 T+1 和交易成本。

### 0.3 宏观、政策、消息与趋势

[开始学习](03-macro-policy-news-regime.md)

把“政策利好”“消息利空”“趋势延续”等口语判断拆成信息时点、预期差、执行工具、公司暴露和状态条件。完成后应能设计不使用未来信息的事件研究。

### 0.4 跨资产、实体经济与另类指标

[开始学习](04-cross-asset-indicators.md)

研究股票与存款、房价、利率、汇率、商品、航运、库存和行业经营数据的关系。完成后应能区分机械关系、经济机制、经验相关与伪相关，并把一个直觉猜想改写成正式研究项目。

## 学习方式

- 第一遍只完成每课的“问题导入”和“典型案例”，建立金融直觉；
- 第二遍学习理论并手工复算关键指标，确保理解数据口径；
- 第三遍完成练习，保留原始数据、代码、图表、失败结果和研究日志；
- 每个结论都写出反例、失效条件和当时可获得的数据，避免把事后解释误当预测能力。

完成四课后，再进入根目录的 [沪深股票量化交易入门到进阶教程](../tutorial.md)，开始数据获取、策略实现和回测。
