# A 股行情、成交、盘口与筹码指标基础

> 课程编号：Lesson 0.2
>
> 更新日期：2026-08-06
>
> 适用对象：数学和机器学习基础较强，但刚开始接触证券交易与市场微观结构。
>
> 定位：解释行情软件中常见的价格、成交、换手、盘口、资金流、筹码和全市场指标。本文不是投资建议，也不把任何单一指标当作买卖信号。

## 1. 问题导入

行情软件同时展示价格、成交量、换手率、资金流、筹码分布和几十种技术指标。初学者真正需要解决的不是“哪个指标最准”，而是：这个数字直接观测到了什么，经过了什么计算，它试图代理哪个不可观测状态，以及它是否能在交易成本后提供增量信息。

完成本课后，你应当能够：

1. 区分原始成交事实、派生统计量和潜变量代理；
2. 解释换手率、盘口、订单流、筹码和波动率指标的计算口径；
3. 从滤波器和状态估计角度理解均线、MACD、RSI、布林带等技术指标；
4. 在 A 股 T+1、涨跌停和成本约束下验证一个技术信号。

### 先回答三个核心问题

#### 实时交易指标究竟能反映什么？

它们主要反映四类信息：

1. **价格发现**：市场当前愿意在哪个价格成交，预期如何变化；
2. **流动性**：想买卖一定数量时，能否快速、低成本成交；
3. **交易压力**：短时间内是买方更急还是卖方更急；
4. **市场状态**：关注度、分歧、波动、拥挤和风险偏好处于什么水平。

它们通常不能直接回答：公司值多少钱、哪类投资者在交易、某笔交易为何发生、当前持有人的真实成本是多少，以及价格明天必然向哪里走。

“成交活跃”与“值得买”是两个问题。高换手可能来自新信息、意见分歧、短线博弈、被动调仓、风险事件或流动性改善；它本身没有固定方向。

#### 这些指标的计算科学吗？

需要分三层回答：

- **事实型指标**：成交价、成交量、买一卖一等是交易所记录或发布的数据，在数据链路正确时属于观测事实；
- **统计型指标**：收益率、VWAP、波动率、订单簿不平衡等是对事实的明确变换，只要公式和口径可复现，就是合格的统计量；
- **模型型指标**：“主力净流入”“筹码获利比例”“庄家成本”等通常包含无法直接观测的分类或递推假设，只是估计量，不是事实。

公式看起来复杂不等于科学。一个指标至少应满足：定义明确、数据可获得时间明确、单位正确、结果可复现、经济含义可解释，并且在样本外扣除交易成本后接受检验。

#### “全市场持仓价格分布”是真实数据吗？

通常不是。

交易所公开行情记录的是订单、成交和价格，并不公开“每个账户现在持有多少股、这些股票的买入成本是多少”。行情软件中的“筹码分布”一般是把历史成交量按价格分桶，再结合换手率假设旧筹码按比例卖出，递推得到的**潜在成本分布**。

这类图可以作为一致口径下的描述性特征，但不能解释为真实账户持仓。后文会给出其典型模型、隐含假设和更稳妥的替代指标。

## 2. 合理假设

技术指标可以研究，但必须先接受它们是条件性统计工具，而不是价格的自然定律。

| 合理假设 | 可证伪含义 | 研究时必须控制的变量 |
| --- | --- | --- |
| 原始价格和成交数据比“资金流”“筹码集中度”等二次标签更接近事实 | 二次指标若在公开原始数据之外持续提供增量信息，才值得保留 | 厂商算法、复权、缺失值 |
| 价格与成交指标反映市场状态，不自动代表因果关系 | 信号在控制风险暴露后消失，说明它可能只是共同状态代理 | 市场、行业、市值、波动率 |
| 指标有效期限应与数据频率和形成机制匹配 | 分钟级不平衡若只能预测数月收益，机制需要重新解释 | 采样频率、持有期、延迟 |
| 技术指标必须相对简单基线提供增量信息 | 复杂指标不能超越收益率、波动率和成交量基线时应放弃 | OHLCV、参数搜索、多重检验 |
| 可交易性是信号定义的一部分 | 加入 T+1、涨跌停、滑点和冲击成本后失效，就不能称为可执行策略 | 成交规则、容量、成本 |

每次使用软件中的现成指标，都应先找到公式、数据源和更新时间；无法解释口径的字段只能作为待验证特征。

## 3. 相关理论与知识

下面从交易制度和原始行情出发，逐层进入成交、盘口、流动性、筹码、波动率和技术指标。顺序很重要：先理解数据怎样产生，再讨论指标可能预测什么。

### 先区分观测量、派生量和潜变量

#### 三层数据地图

| 层级 | 例子 | 是否直接观测 | 主要问题 |
| --- | --- | --- | --- |
| 交易所事件 | 委托、撤单、成交、交易状态 | 是，但需要相应授权数据 | 序号、时间戳、漏包、重复、频道合并 |
| 行情快照 | 最新价、累计量额、五档/十档盘口 | 是，是某一时刻的切片 | 快照之间发生的事件可能丢失 |
| K 线 | 开高低收、成交量、成交额 | 由区间事件聚合 | 区间内路径和先后顺序被压缩 |
| 确定性派生指标 | 收益率、VWAP、价差、换手率 | 否，但公式可复现 | 口径、单位、复权、分母选择 |
| 规则分类指标 | 主动买入、主动卖出、大单资金流 | 否 | 买卖方向和“大单”阈值可能是估计 |
| 潜变量模型 | 筹码成本、主力意图、情绪状态 | 否 | 强依赖模型假设，通常无法直接验证真值 |

量化研究最重要的习惯之一，是给每个字段附上元数据：

```text
字段名称       turnover_rate
原始来源       某数据供应商日线接口
计算公式       当日成交股数 / 当日流通股本
单位           百分比
时间可用性     当日收盘后
复权口径       成交量不复权，股本为当日股本
异常处理       停牌为空；上市首日单独标记
版本           provider_schema_v3
```

没有这张“指标身份证”，以后很容易把同名异义的字段混在一起。

#### Level-1、Level-2 和逐笔不是同一种数据

以股票连续竞价为例，交易所 Level-1 即时行情通常包括最新价、最高价、最低价、累计成交量、累计成交额和五档买卖价格及数量。它告诉你“当前快照是什么样”，但不能完整恢复两个快照之间的订单变化。

Level-2 通常提供更多档位、更细的订单队列信息以及逐笔委托/成交等数据。深交所技术规范明确，逐笔委托和逐笔成交按发生顺序在同一数据流中发送，并使用连续记录号。研究撤单、队列和订单流时，记录号与交易状态和价格同样重要。

可以把数据能力粗略理解为：

| 数据 | 能可靠研究什么 | 不能可靠研究什么 |
| --- | --- | --- |
| 日 K | 中低频收益、成交、换手、横截面因子 | 日内顺序、真实盘口冲击 |
| 分钟 K | 日内形态、分时量价、近似 VWAP | 单笔方向、撤单、排队位置 |
| Level-1 快照 | 最优价差、五档深度的快照特征 | 快照间完整订单流 |
| 逐笔成交 | 成交分布、成交方向的近似或标记 | 未成交意愿、完整撤单行为 |
| 逐笔委托与成交 | 订单流、撤单、队列变化、冲击 | 投资者真实身份和持仓成本 |
| 自己的委托回报 | 自己的成交率、滑点和排队结果 | 其他账户的策略与成本 |

#### 时间戳也有层级

高频数据至少可能有以下时间：

- 交易所事件发生时间；
- 行情网关发送时间；
- 数据供应商接收和转发时间；
- 你的程序接收时间；
- 本地落盘时间。

日频初学者也不能忽略时间：15:00 才完整形成的收盘价、成交量和换手率，不能假设自己在 14:59 已经知道最终值。研究盘中策略时，必须用当时的累计量而不是全天最终量。

### A 股交易时段决定指标含义

根据沪深交易所现行规则，普通竞价交易日大致分为：

- `09:15--09:25`：开盘集合竞价；
- `09:30--11:30`：上午连续竞价；
- `13:00--14:57`：下午连续竞价；
- `14:57--15:00`：收盘集合竞价。

`09:20--09:25` 和收盘集合竞价阶段通常不接受撤单。集合竞价与连续竞价的价格形成机制不同，不能用同一套盘口解释。

#### 集合竞价看什么？

集合竞价不是每来一单就成交，而是把有效申报集中起来，按规则选择一个使成交量最大等条件成立的价格。期间行情会揭示：

- **虚拟参考价格**：如果现在撮合，可能形成的集合竞价价格；
- **虚拟匹配量**：按该价格能够成交的申报数量；
- **虚拟未匹配量**：仍无法匹配的买方或卖方数量。

这些数值能描述当时的供需不平衡，但在允许撤单的阶段可能快速变化。`09:15--09:20` 出现的大买单不等于最终愿意成交；不可撤单阶段的信息约束更强，但仍不保证开盘后的方向。

#### 连续竞价看什么？

连续竞价遵循价格优先、时间优先。此时最新成交价反映刚刚发生的交易，订单簿反映尚未成交的限价意愿。需要牢记：

- 成交是已发生事实，挂单只是可撤销意愿；
- 买一的大挂单不等于价格一定上涨；
- 价格碰到涨跌停时，盘口和流动性的统计性质会突变；
- 午间休市、临时停牌、复牌集合竞价应单独标记；
- 尾盘集合竞价形成的收盘价可能承载指数跟踪和收盘估值需求，与普通分钟不同。

#### T+1 对实时指标有什么影响？

当天新买入的普通 A 股不能当天卖出，因此日内卖方主要来自此前持仓，而买方可能是新资金或已有资金加仓。这个制度会影响日内反转、涨停排队和隔夜风险，但不能由此推出“高换手就是旧筹码已全部换成新筹码”。同一批可卖股份可以在不同账户间多次转手，成交量不是唯一股份的计数。

### 价格与“成交点位”

“成交点位”不是严格统一的专业术语，至少可能指四件事：

1. 一笔股票成交的价格；
2. 成交价在当日高低区间中的位置；
3. 成交价相对 VWAP、昨收或盘口中间价的位置；
4. 成交发生时上证指数、沪深 300 等指数的点位。

研究时必须改写成明确变量，不能直接使用“点位高/低”这种自然语言。

#### 最新价、开盘价、收盘价

**最新价**是最近一笔成交价格。它可能已经陈旧：不活跃股票几分钟没有成交时，最新价并不代表现在立刻能成交的价格。

**开盘价**通常由开盘集合竞价的第一笔成交形成；不能形成时再由连续竞价产生。

**收盘价**通常由收盘集合竞价形成。收盘价是净值、指数和很多回测的锚点，但并不意味着你能把大额订单无冲击地按收盘价成交。

最基本的收盘收益率为：

```math
r_t=\frac{C_t}{C_{t-1}}-1.
```

若跨分红、送股等公司行动，应使用总收益或正确复权序列计算信号；模拟真实委托和涨跌停时保留不复权价格。

#### 跳空、振幅和区间位置

开盘跳空可写为：

```math
\mathrm{Gap}_t=\frac{O_t}{C_{t-1}}-1.
```

一种常用振幅口径是：

```math
\mathrm{Range}_t=\frac{H_t-L_t}{C_{t-1}}.
```

收盘在日内区间的位置可写为：

```math
\mathrm{CLV}_t=\frac{2C_t-H_t-L_t}{H_t-L_t}.
```

它通常在 `[-1,1]`：接近 1 表示收在日内高位，接近 -1 表示收在日内低位。当 `H_t=L_t` 时必须定义缺失或单独处理，不能除以零。

这些变量描述价格路径的压缩摘要，不说明因果。高位收盘可能是信息继续发酵，也可能是短期过度反应。

#### VWAP 与 TWAP

若第 $i$ 笔成交价为 $p_i$ 、成交量为 $q_i$ ，成交量加权平均价为：

```math
\mathrm{VWAP}=\frac{\sum_i p_iq_i}{\sum_i q_i}.
```

若数据中的成交额 $A$ 与成交股数 $V$ 单位匹配，也可近似写成：

```math
\mathrm{VWAP}=\frac{A}{V}.
```

但供应商可能用“手”“股”“元”“千元”或“万元”，必须先做单位审计。对随机抽取的交易日检查 VWAP 是否落在当日最低价和最高价之间，是很有用的质量测试。

TWAP 是等时间权重平均价格。VWAP 更贴近市场成交量分布，TWAP 更强调时间均匀。二者主要是执行基准，不天然是“合理价值”。

可构造相对 VWAP 偏离：

```math
d_t=\frac{P_t-\mathrm{VWAP}_t}{\mathrm{VWAP}_t}.
```

正偏离说明当前价格高于当日成交均价，不自动等于“超买”。趋势行情中偏离可持续扩大。

#### 买一、卖一、中间价和价差

设最优买价为 $b_t$ ，最优卖价为 $a_t$ ：

```math
m_t=\frac{a_t+b_t}{2},\qquad
s_t=a_t-b_t,\qquad
s_t^{\mathrm{rel}}=\frac{a_t-b_t}{m_t}.
```

- $m_t$ 是中间价，常用于估计当时的无方向价格；
- $s_t$ 是绝对买卖价差；
- $s_t^{\mathrm{rel}}$ 是相对价差，便于不同价格股票间比较。

价差越小通常表示小额立即成交成本越低，但它只看最优一档。大额订单还要看后续深度。

若成交方向 $x_i$ 取主动买入为 $+1$ 、主动卖出为 $-1$ ，成交价为 $p_i$ ，当时中间价为 $m_i$ ，有效价差可估计为：

```math
s_i^{\mathrm{eff}}=2x_i\frac{p_i-m_i}{m_i}.
```

这比报价价差更接近实际立即成交成本，但依赖正确的成交方向与时间对齐。

#### Microprice：把一档数量加入价格

设买一量为 $Q_b$ 、卖一量为 $Q_a$ ，常见 microprice 为：

```math
\mathrm{Microprice}
=\frac{a_tQ_b+b_tQ_a}{Q_b+Q_a}.
```

买一量大时，它更接近卖价；卖一量大时，更接近买价。其含义是用最优档不平衡修正中间价，常用于非常短的预测周期。

它不是“未来真实价格”：挂单可撤、隐藏流动性不可见、不同价位补单速度不同，而且日频投资者几乎无法凭这一微小优势覆盖延迟和费用。

#### 指数点位不是股票价格

指数一般由样本证券价格和调整股本等按编制方案聚合，并通过除数修正维持公司行动前后的连续性。指数从 3000 点到 3030 点是约 1% 的指数变化，不表示所有股票上涨 1%，更不表示市场“增加了 30 元”。

市值加权指数可能被少数大权重股推动。理解全市场状态时，应同时看等权收益、中位数收益和上涨家数，而不是只看指数点位。

### 成交量、成交额与换手率

#### 三者分别是什么？

- **成交量**：一段时间内成交的股数或手数；
- **成交额**：成交价乘成交数量后求和；
- **换手率**：成交活动相对股本或市值规模的比例。

成交量不能直接跨股票比较。10 万股贵州茅台与 10 万股低价小盘股对应的资金、流通盘比例和冲击完全不同。成交额解决价格尺度问题，换手率进一步处理规模问题，但也引入分母口径问题。

#### 换手率至少有两种正式口径

证券期货业统计指标标准把股本换手率定义为：

```math
\mathrm{TR}^{\mathrm{share}}_t
=\frac{\text{当日成交股数}}{\text{当日流通股本}}\times100\%.
```

市值换手率可写为：

```math
\mathrm{TR}^{\mathrm{value}}_t
=\frac{\text{当日成交金额}}{\text{当日流通市值}}\times100\%.
```

但不同页面或供应商也可能使用总股本、自由流通股本、实际上市流通量或平均市值。结论是：**永远不要只保存字段名 `turnover`，还要保存口径。**

#### 换手率超过 100% 是否错误？

不一定。换手率统计成交股数，不是统计“有多少独一无二的股票换了主人”。同一股在统计区间内可以多次成交，所以月度换手率超过 100% 很常见，极端活跃股票的单日换手也可能很高。

因此，以下说法通常不成立：

> 换手率 50%，所以恰好有一半股东离场，另一半股东进入。

你最多能说：当日累计成交股数相当于所用分母股本的 50%。它无法识别唯一股份、唯一账户和持有期。

#### 高换手和低换手能说明什么？

**高换手可能对应：**

- 新信息到来，引发重新定价；
- 投资者意见分歧扩大；
- 题材关注、短线资金和交易拥挤；
- 指数调仓、解禁、减持或机构再平衡；
- 流动性良好，交易成本相对低；
- 价格处于大幅上涨或下跌中的强制换仓。

**低换手可能对应：**

- 市场缺少关注或信息；
- 长期持有人稳定；
- 自由流通盘实际较小；
- 停牌、涨跌停封单或价格缺乏对手盘；
- 股票流动性差，想交易也无法成交。

所以“缩量”既可能是抛压减弱，也可能是买盘消失；“放量”既可能确认趋势，也可能是分歧见顶。方向需要和收益、相对历史、市场状态及后续表现联合检验。

#### 相对成交量比绝对成交量更有意义

日频可以定义过去 $L$ 日中位数归一化：

```math
\mathrm{RVOL}_t
=\frac{V_t}{\mathrm{median}(V_{t-L},\ldots,V_{t-1})}.
```

中位数比均值对极端放量更稳健。盘中不能拿 10:00 的累计量除以全天平均量；应该与历史上**相同交易时刻**的累计量比较：

```math
\mathrm{RVOL}_{t,\tau}
=\frac{V_{t,\tau}^{\mathrm{cum}}}
{\mathrm{median}_{d<t}(V_{d,\tau}^{\mathrm{cum}})}.
```

这里 $\tau$ 表示交易时刻。这样才能消除日内成交量通常开盘和收盘较高的季节性。

#### 成交笔数和平均每笔成交

若数据提供成交笔数 $N_t$ ：

```math
\mathrm{AvgTradeSize}_t=\frac{V_t}{N_t}.
```

平均每笔变大可能表示订单规模变化，但不能直接解释为“机构进场”：算法可以拆单，多个小账户也可同时交易，交易所的一笔成交也不等于投资者的一张完整订单。

### 盘口、订单流与成交方向

#### 五档或十档深度

设前 $K$ 档买量、卖量分别为 $Q^b_k,Q^a_k$ ，盘口不平衡可写为：

```math
\mathrm{OBI}_{t,K}
=\frac{\sum_{k=1}^{K}Q^b_{t,k}-\sum_{k=1}^{K}Q^a_{t,k}}
{\sum_{k=1}^{K}Q^b_{t,k}+\sum_{k=1}^{K}Q^a_{t,k}}.
```

它在 `[-1,1]`。正值表示可见买方挂单更多，负值表示可见卖方挂单更多。

OBI 在秒级或更短周期可能与下一次价格变化有关，但它有明显边界：

- 只看到公开档位内的限价单；
- 挂单可以撤销；
- 各档离中间价距离不同，简单相加不一定合理；
- 涨跌停时单侧队列使指标饱和；
- 大盘股与小盘股、开盘与午间的基线不同；
- 你的下单会改变队列位置和可成交结果。

可以给近端档位更大权重，但权重必须在训练期定义，并在样本外验证。

#### “主动买入”和“主动卖出”是什么意思？

每笔成交同时有买方和卖方，所以从会计恒等式看，成交量的买卖双方永远相等。行情软件所谓“主动买入”通常指：买方订单主动跨过价差，与已有卖单成交；“主动卖出”反之。

若逐笔数据直接给出订单关联或成交方向，可以按交易所字段构造。若只有成交价和报价，就需要推断。例如：

- 成交价高于当时中间价，推断为买方主动；
- 成交价低于中间价，推断为卖方主动；
- 在中间价附近时，用相对上一笔成交价的 tick rule 辅助分类。

Lee--Ready 论文表明，成交方向推断会受到成交与报价时间对齐、价差内成交等问题影响。这个结论比具体的“延迟几秒”更重要：**分类结果是算法输出，不是真实标签。**现代中国电子订单簿的字段与时延也不同，不能机械照搬 1991 年美股参数。

#### 订单流不平衡

若每笔成交的方向为 $x_i\in\lbrace -1,+1\rbrace$ ，数量为 $q_i$ ，区间内带符号成交量为：

```math
\mathrm{SignedVolume}_t=\sum_{i\in t}x_iq_i.
```

归一化后：

```math
\mathrm{TradeImbalance}_t
=\frac{\sum_i x_iq_i}{\sum_i q_i}.
```

这表示区间内哪一方更愿意立即成交。它可能解释极短期价格压力，但不必然预测更长周期收益：买方主动推动价格后，信息可能继续被吸收，也可能发生反转。

更完整的订单流还应包括新增限价单、撤单和成交对最佳买卖档数量的改变。只看成交而忽略撤单，会漏掉大量流动性变化。

#### 大单、封单和撤单

“大单”只有在定义了阈值后才有意义：固定股数、固定金额、占流通市值比例、占同期成交比例，结论都不同。

常见误区：

- 一笔大成交不等于一个机构的一张订单；
- 许多小成交不等于散户交易；
- 涨停封单很大不等于一定能封到收盘；
- 反复挂撤的订单可能是流动性管理，也可能是试探或异常行为，不能仅凭图形判定动机；
- 排在队列末端的买单数量不能当作你一定能成交的数量。

对大单更科学的处理是按股票自身成交额分位数、占 ADV 比例或占可见深度比例标准化，而不是全市场使用一个固定万元阈值。

### 流动性和价格冲击

#### 流动性不是成交量的同义词

流动性至少包含：

- **紧度**：买卖价差有多小；
- **深度**：不同价格可成交多少；
- **即时性**：多快能完成交易；
- **韧性**：大单冲击后订单簿多快恢复。

成交量高的股票通常更容易交易，但如果当时波动剧烈、价差扩大或单边跌停，历史高成交量并不能保证当前流动性。

#### Amihud 非流动性指标

使用日线数据可计算：

```math
\mathrm{ILLIQ}_{i,t}
=\frac{|r_{i,t}|}{A_{i,t}},
```

其中 $A_{i,t}$ 为成交额。它近似衡量单位成交金额伴随的绝对价格变化。数值越大，通常表示价格对成交额更敏感、流动性更差。

注意：

- 成交额使用元、万元会改变数值尺度；
- 跨市场比较前需统一币种和缩放；
- 日涨跌停和极小成交额会制造极端值；
- 这是粗略代理变量，不是交易一笔特定订单的真实冲击函数。

Amihud 原论文也明确把它定位为易从日频数据得到的粗略价格冲击度量，并指出买卖价差和逐笔冲击等更细指标。

#### Kyle lambda 的直觉

可用价格变化对带符号订单流做回归：

```math
\Delta m_t=\alpha+\lambda Q_t^{\mathrm{signed}}+\varepsilon_t.
```

$\lambda$ 越大，单位净订单流对应的价格变化越大，可解释为深度更差或信息冲击更强。但实证估计面临内生性：交易方向和价格共同由信息驱动，时间桶选择、方向分类、异方差与非线性都会影响结果。

#### 策略容量

回测中“每天按收盘价买入 1000 万元”通常不现实。至少要记录：

```math
\mathrm{ParticipationRate}
=\frac{\text{你的成交量}}{\text{同期市场成交量}}.
```

参与率越高，冲击通常越大。一个信号有统计显著性，不表示可以承载足够资金。小盘、低价、涨跌停股票尤其需要成交量上限、滑点模型和无法成交情景。

### “资金流入/流出”到底是什么

#### 单只股票没有字面意义上的净流入

一笔 100 万元成交同时对应买方支付 100 万元、卖方收到 100 万元。就这只股票的二级市场成交而言，买卖金额相等，不存在凭空多出的“净流入”。

行情软件常见的净流入近似为：

```math
\mathrm{NetFlow}_t
=\sum_{i\in\mathrm{active\ buy}}p_iq_i
-\sum_{i\in\mathrm{active\ sell}}p_iq_i.
```

所以它更准确的名字应是“按某种算法分类的主动买卖成交额差”。它衡量的是交易发起压力，而不是资产负债表中的现金流，也不是已知投资者身份的资金迁移。

#### “主力资金”为什么尤其要谨慎？

常见软件先按单笔金额把成交分成超大单、大单、中单、小单，再把大额主动买卖相减。这隐含了两个未经保证的假设：

1. 大成交来自机构或所谓主力；
2. 成交方向分类正确。

现实中机构会拆单，散户订单也会被撮合成大成交，一张大订单可拆成许多交易回报。不同软件阈值和算法不同，同一股票可能给出不同“主力净流入”。

更稳妥的研究方式：

- 把它命名为 `large_trade_signed_amount`，不写成 `institution_flow`；
- 保存供应商、阈值和方向规则；
- 用总成交额归一化；
- 检验它对下一时段收益、波动和流动性的增量解释力；
- 与简单收益、成交量、订单簿不平衡比较，防止只是重复编码当期涨跌。

### 筹码分布、持仓成本与成交量分布

#### 先区分三个概念

**真实账户持仓成本**：每个当前持有人买入批次、数量、费用和公司行动调整后的成本。这需要账户级流水，公开行情无法得到。

**成交量价格分布（Volume Profile）**：某个明确窗口中，不同价格区间实际成交了多少。这可以由逐笔成交聚合，是历史成交事实。

**筹码分布模型**：估计“目前仍被持有的股份”最可能分布在哪些成本区间。它需要假设旧持仓如何卖出，属于潜变量估计。

不要把后两者画成相似的横向柱状图，就认为它们含义相同。

#### 可直接计算的成交量价格分布

把价格划分为区间 $B_j$ ，窗口 $W$ 内的成交量分布为：

```math
V_W(B_j)=\sum_{i\in W}q_i\,\mathbf{1}(p_i\in B_j).
```

由此可观察：

- 哪些价格区间历史成交密集；
- 当前价格距离窗口成交量加权中心多远；
- 高成交密集区是否可能成为交易者关注的参考区；
- 突破后，价格是否离开了此前主要成交区。

它仍有局限：同一股可能在窗口内成交多次，所以柱子的总和不是“当前持仓”；窗口起点和价格分桶宽度会显著影响图形；历史成交密集区也不会产生物理意义上的支撑或阻力。

#### 常见筹码模型如何递推

设 $W_{t-1}(p)$ 是前一日估计的成本分布， $h_t$ 是当日换手比例， $f_t(p)$ 是把当日成交量分配到价格区间后的分布。一个简化递推是：

```math
W_t(p)=(1-h_t)W_{t-1}(p)+h_tf_t(p).
```

直觉是：假设旧筹码中有比例 $h_t$ 被均匀卖出，再把同等比例的新筹码按当日成交价格加入。

如果只有日 K，软件还需要猜测当日成交在最低价到最高价间如何分配，例如均匀、三角形或围绕均价的经验分布。这又增加了一层假设。

#### 模型的关键假设为何不真实？

1. **等概率卖出假设**：不同成本、持有期和投资者的卖出概率并不相同；
2. **换手即替换假设**：同一股份可日内或多日多次转手，换手率不是唯一持仓更新比例；
3. **成交分配假设**：日 K 无法恢复区间内真实成交价格分布；
4. **账户不可识别**：无法知道交易是新开仓、加仓、减仓还是不同账户间轮转；
5. **自由流通分母误差**：限售、解禁、大股东不活跃持仓和供应商股本更新会改变结果；
6. **公司行动**：分红、拆并股、配股需要同步调整历史成本与数量；
7. **窗口和初始化依赖**：模型从哪一天开始、初始成本如何设定，会长期影响输出。

因此，“90% 筹码集中在 10--12 元”应改写为：

> 在软件商给定的换手递推与日内成交分配模型下，估计分布的 90% 质量位于该区间。

这不是咬文嚼字，而是区分观测事实与模型输出。

#### 获利盘、平均成本和集中度

如果把 $W_t(p)$ 归一化为概率分布，当前价格 $P_t$ 下的模型获利比例为：

```math
\mathrm{WinnerRate}_t=\int_{p<P_t}W_t(p)\,dp.
```

平均估计成本为：

```math
\bar p_t=\int pW_t(p)\,dp.
```

还可计算 5%--95% 分位区间宽度、熵或方差描述集中程度。但这些派生量不会比底层 $W_t$ 更真实；模型假设错时，小数点再精确也没有意义。

#### 科学地使用筹码类指标

可接受的研究方式：

1. 完整复现算法，不依赖软件截图；
2. 同时构造真实滚动 Volume Profile、anchored VWAP 等较少假设的基线；
3. 固定初始化、窗口、分桶和公司行动规则；
4. 检验筹码特征是否在价格、动量、换手和波动之外提供增量信息；
5. 做时间滚动和横截面样本外检验；
6. 不用“庄家成本”“套牢盘必然抛售”作为不可证伪解释。

如果复杂筹码模型不能稳定优于“过去 60 日按价格分桶的成交量分布”或“事件日起 anchored VWAP”，就没有必要使用它。

### 波动率与风险状态指标

#### 历史波动率

日收益率在滚动窗口内的年化波动率可写为：

```math
\sigma_{t,L}=\sqrt{252}\,\mathrm{std}(r_{t-L+1},\ldots,r_t).
```

它描述过去波动，不是保证未来波动。窗口越短越灵敏也越噪，窗口越长越稳定也越迟钝。

#### 已实现波动率

把一天分成多个区间，区间对数收益为 $r_{t,j}$ ：

```math
\mathrm{RV}_t=\sum_j r_{t,j}^2,\qquad
\mathrm{RealizedVol}_t=\sqrt{\mathrm{RV}_t}.
```

高频采样在理论上能更充分利用日内信息，但频率过高会受到买卖价差跳动、价格离散、异步交易和数据错误影响。实践中常比较 1 分钟、5 分钟、10 分钟结果，而不是盲目使用最高频率。

#### True Range 与 ATR

真实波幅考虑隔夜跳空：

```math
\mathrm{TR}_t=\max\{H_t-L_t,|H_t-C_{t-1}|,|L_t-C_{t-1}|\}.
```

ATR 是 TR 的滚动平均或平滑平均。它常用于把止损距离、仓位和价格尺度标准化，但 ATR 不是损失上限；连续跌停和跳空可以远超预设止损价。

#### 上行和下行波动

可以把已实现方差拆成：

```math
\mathrm{RV}_t^+=\sum_j r_{t,j}^2\mathbf{1}(r_{t,j}>0),\qquad
\mathrm{RV}_t^-=\sum_j r_{t,j}^2\mathbf{1}(r_{t,j}<0).
```

下行波动、跳空、跌停封单、市场相关性上升，通常比对称标准差更接近投资者的短期风险体验。

### 常见技术指标在数学上做了什么

技术指标大多是 OHLCV 的平滑、差分、排序、归一化或非线性变换，并没有创造新数据。它们可以用来压缩状态、统一尺度和构造交易规则，但不应因为有专有名称就被赋予特殊因果含义。

先把指标按数学作用分成五类：

| 类别 | 典型指标 | 数学作用 | 主要试图描述 |
| --- | --- | --- | --- |
| 趋势 | SMA、EMA、双均线、MACD、ADX | 平滑、差分 | 价格方向及趋势强弱 |
| 动量 | ROC、RSI、随机指标 | 差分、正负分解、区间归一化 | 近期涨跌速度和位置 |
| 波动 | ATR、布林带宽度 | 极差、标准差、平滑 | 正常价格波动尺度 |
| 通道与突破 | 布林带、Donchian 通道 | 滚动极值或均值加减尺度 | 当前价格相对历史区间的位置 |
| 量价 | OBV、MFI、相对成交量 | 成交量加权或有符号累积 | 价格运动是否伴随成交活动 |

同一类别中的指标往往高度相关。增加十个相似指标通常不会增加十份独立信息。

#### SMA 与 EMA：先理解一条均线

##### 简单移动平均

长度为 $L$ 的简单移动平均为：

```math
\mathrm{SMA}_{t,L}=\frac{1}{L}\sum_{j=0}^{L-1}C_{t-j}.
```

它把最近 $L$ 个收盘价赋予相同权重。每过一个交易日，加入最新价格并删除窗口最早价格。因此，均线当天的变化不只取决于今天价格，还取决于被移出窗口的旧价格：

```math
\mathrm{SMA}_{t,L}-\mathrm{SMA}_{t-1,L}
=\frac{C_t-C_{t-L}}{L}.
```

这个等式很重要：均线向上并不要求今天上涨，只要求今天价格高于 $L$ 日前被移出的价格。

SMA 是低通平滑器。它减少日间噪声，同时付出滞后代价。对近似线性趋势，长度为 $L$ 的 SMA 有约 $(L-1)/2$ 个交易日的中心滞后。因此，均线不是在趋势开始时给出信号，而是在趋势已经持续一段时间后确认状态。

##### 指数移动平均

EMA 递推为：

```math
\mathrm{EMA}_{t,L}
=\alpha C_t+(1-\alpha)\mathrm{EMA}_{t-1,L},
\qquad
\alpha=\frac{2}{L+1}.
```

展开递推后，较早价格的权重按几何速度衰减：

```math
\mathrm{EMA}_{t,L}
=\alpha\sum_{j=0}^{\infty}(1-\alpha)^jC_{t-j}.
```

与同名长度的 SMA 相比，EMA 对最新价格反应通常更快，但也更容易被短期波动触发。参数 $L$ 在 EMA 中是常用的 span 约定，不表示只使用最近 $L$ 天；理论上更早数据仍有很小权重。

EMA 还依赖初始化。常见做法包括用第一个价格初始化，或先用前 $L$ 日 SMA 初始化。样本开始后的早期数值可能因软件实现而不同，所以研究代码应设置至少一个慢均线长度的预热期，并记录所用实现。

##### 一条均线的三种不同信号

一条均线就可以构造三个含义不同的特征：

1. **价格位置**： $C_t>\mathrm{MA}_{t,L}$ ，表示当前价格高于近期平滑价格；
2. **均线斜率**：`MA(t, L)` 高于 `MA(t-k, L)`，表示平滑价格正在上升；
3. **标准化距离**：

```math
d_{t,L}=\frac{C_t-\mathrm{MA}_{t,L}}{\mathrm{ATR}_{t,L}}
```

或除以当前价格。标准化后更适合跨股票比较。

“价格高于均线”不等于“均线向上”。价格刚从低位反弹时可能已经在均线上方，而均线仍在下降。研究中应明确自己用的是位置、斜率还是二者共同成立。

#### 双均线趋势策略

##### 它的精确定义

设快速均线长度 $L_f$ 小于慢速均线长度 $L_s$ ：

```math
F_t=\mathrm{MA}_{t,L_f},\qquad
S_t=\mathrm{MA}_{t,L_s},\qquad
D_t=F_t-S_t.
```

最简单的多头趋势状态为：

```math
I_t=\mathbf{1}(D_t>0).
```

- $I_t=1$ ：快速均线高于慢速均线，策略处于持有状态；
- $I_t=0$ ：快速均线不高于慢速均线，策略持有现金。

这是一种**状态规则**。所谓金叉只是状态从 0 变成 1 的事件：

```math
\mathrm{CrossUp}_t
=\mathbf{1}(D_t>0,\ D_{t-1}\leq0).
```

死叉则是从 1 变成 0。不能把“今天发生金叉”和“目前仍处于多头状态”混为一谈：前者只在交叉当天为真，后者可能连续维持数月。

为了跨股票或跨时期比较，可以把绝对均线差标准化：

```math
D_t^{\mathrm{price}}=\frac{F_t-S_t}{C_t},
\qquad
D_t^{\mathrm{vol}}=\frac{F_t-S_t}{\mathrm{ATR}_{t,L}}.
```

10 元股票与 100 元股票的 1 元均线差含义不同；除以价格或 ATR 后才有较一致的尺度。

##### 它为什么可能捕捉趋势？

快速均线主要反映较近价格，慢速均线保留更长历史。当近期价格整体高于更早价格时，快速均线通常先上升并超过慢速均线。

从信号处理角度看，双均线是两个不同平滑尺度的低通滤波器之差，近似提取某个中间频段的价格变化。从金融角度看，它押注趋势延续，可能对应：

- 信息被不同投资者逐步吸收，而不是瞬间完全反映；
- 资金持续流入或流出；
- 机构分批建仓、减仓；
- 投资者锚定、处置效应或追涨行为；
- 宏观与行业趋势持续一段时间。

这些只是可能机制。即使历史上策略赚钱，也不能仅凭收益曲线识别究竟是哪一种机制。

##### 20/60 日代表什么？

20 个交易日大约对应一个交易月，60 日大约对应一个季度，所以 20/60 是便于理解的教学参数。它们不是由金融定律推导出的最优常数。

常见参数组合的大致性格：

| 快/慢窗口 | 大致反应 | 典型问题 |
| --- | --- | --- |
| 5/20 | 快，交易较频繁 | 对噪声敏感，震荡期成本高 |
| 20/60 | 中等，适合教学 | 仍可能在转折后较晚退出 |
| 50/200 或 60/250 | 慢，强调长期趋势 | 信号少、滞后大、样本事件少 |

窗口越短，响应越快但假信号通常越多；窗口越长，信号更平滑但可能错过趋势前段。这里没有免费午餐。

##### 正确的 A 股信号时序

若均线使用交易日 $t$ 的收盘价， $D_t$ 只能在当日收盘数据形成后最终确定。因此：

1. 用截至 $t$ 日收盘的数据计算均线；
2. 收盘后得到 $I_t$ ；
3. 最早在 $t+1$ 日按可实现价格委托；
4. 回测持仓使用至少一日位移；
5. 若 $t+1$ 停牌或涨停买不到，应保留现金或未完成订单；
6. 若持仓在跌停无法卖出，不能假设按开盘价或收盘价退出。

主教程采用“ $t$ 日收盘确认， $t+1$ 开盘交易”。也可以研究 $t+1$ VWAP 或固定时刻成交，但必须提前定义，并加入相应滑点和无法成交规则。

A 股普通股票 T+1 还意味着当天买入后不能当天卖出。对日频双均线通常不是主要限制，因为状态不会在一个收盘信号内来回切换；对盘中均线频繁反转策略则可能直接改变可执行逻辑。

##### 双均线为何经常失效？

**震荡反复**：价格在区间内上下穿越，快速均线反复跨越慢速均线，形成连续小亏和交易成本。这称为 whipsaw。

**趋势反转滞后**：均线依赖历史数据。突发利空、跳空和连续跌停发生时，死叉可能远晚于实际风险开始。

**单只股票事件风险**：公司造假、退市风险、行业政策和并购事件不是一般趋势滤波能够解决的。

**长期横盘后的假突破**：波动暂时放大即可造成交叉，后续没有持续资金或信息推动。

**牛市暴露伪装成 alpha**：长期只做多策略可能只是减少了部分熊市暴露。若只和现金比较而不和买入持有、等风险基准比较，很容易高估信号价值。

**成本与现金收益遗漏**：短参数交易频繁；空仓期间的现金收益、佣金、印花税、滑点和最低佣金都会改变结果。

##### 常见改进及其代价

**加入缓冲带**：

```math
I_t=\mathbf{1}\left(\frac{F_t-S_t}{C_t}>\varepsilon\right).
```

退出可使用更低阈值，形成迟滞区间。例如进入阈值为正，退出阈值为零或负。这样可减少边界来回切换，但会进一步延迟。

**要求连续确认**：信号连续 $k$ 日成立才交易。它降低偶然交叉，也会错过快速行情。

**加入慢均线斜率**：只在快速均线高于慢速均线且慢均线向上时持有。规则更保守，但和原信号高度相关。

**按波动调整仓位**：趋势状态决定方向，ATR 或波动率决定仓位。这样可降低高波动时期风险，但需要杠杆和仓位上限。

**使用多资产分散**：把规则用于宽基 ETF、行业 ETF 或流动性股票组合，比单只股票更能分散公司特有风险。

**改用突破规则**：例如收盘突破过去 60 日最高价时进入。它仍是趋势策略，只是从“平滑交叉”改成“区间突破”，不保证更优。

每增加一条过滤条件都会增加参数和数据挖掘自由度。改进必须与原始双均线在同一成本、同一测试期和同一股票池下比较。

##### 应怎样评价？

除了 CAGR、Sharpe 和最大回撤，还应报告：

- 平均市场暴露和空仓比例；
- 年换手率、交易次数和平均持有期；
- 单次交易收益的均值、中位数和尾部；
- 牛市、熊市、震荡市的分段表现；
- 相对买入持有的收益与回撤；
- 等波动或等暴露基准下的增量收益；
- 参数邻域热图，而不是只报告最优参数点；
- 成本按 0.5 倍、1 倍、2 倍变化时的结果；
- 不同股票、指数 ETF 和不同年代的稳定性。

若 19/59 很好而 20/60 很差，通常说明结果不稳健。更可信的现象应在一片相邻参数区域内方向大致一致，而不是只在一个尖锐参数点上成立。

#### MACD：多尺度 EMA 差

##### 标准定义

最常见参数是 12、26、9。先计算短期和长期 EMA：

```math
\mathrm{DIF}_t=\mathrm{EMA}_{t,12}-\mathrm{EMA}_{t,26}.
```

再对 DIF 做 9 期 EMA：

```math
\mathrm{DEA}_t=\mathrm{EMA}_{9}(\mathrm{DIF})_t.
```

柱状值通常定义为：

```math
\mathrm{Hist}_t=\mathrm{DIF}_t-\mathrm{DEA}_t.
```

部分中国行情软件显示的 MACD 柱为 $2(\mathrm{DIF}-\mathrm{DEA})$ 。两者只有尺度差异，但如果你拿软件截图与代码核对，必须先确认这一口径。

##### 三类常见信号

- DIF 大于零：短期 EMA 高于长期 EMA，类似双均线多头状态；
- DIF 上穿 DEA：多尺度差值的短期变化转强；
- 柱状值扩大或缩小：DIF 与其平滑值之间的距离变化。

所谓“零轴上方金叉”同时要求中期趋势为正和短期变化转强，比单纯金叉更严格，也更滞后。

MACD 的柱状值并不是成交量，也不是资金流。它的单位仍然是价格。跨股票比较时可除以价格或 ATR：

```math
\mathrm{MACDNorm}_t=\frac{\mathrm{Hist}_t}{C_t}
```

或使用波动率标准化。

##### MACD 的主要局限

MACD、双 EMA、不同窗口动量高度相关。把它们一起加入模型可能只是重复表达“近期价格高于较早价格”。标准 12/26/9 不是自然规律，在日线、分钟线和周线上的实际时间含义也不同。

“顶背离”“底背离”若只靠肉眼选择峰谷，具有很强事后性。若要研究背离，必须事先定义峰谷识别、最小间隔、幅度阈值和交易时点。

#### RSI：近期上涨和下跌幅度的比例

##### Wilder 口径

设收盘变化为：

```math
\Delta_t=C_t-C_{t-1}.
```

正向和负向幅度为：

```math
G_t=\max(\Delta_t,0),
\qquad
L_t=\max(-\Delta_t,0).
```

对 $n$ 日 RSI，Wilder 平滑可写成：

```math
\bar G_t=\frac{(n-1)\bar G_{t-1}+G_t}{n},
\qquad
\bar L_t=\frac{(n-1)\bar L_{t-1}+L_t}{n}.
```

RSI 可稳定地写为：

```math
\mathrm{RSI}_t
=100\times\frac{\bar G_t}{\bar G_t+\bar L_t}.
```

若窗口内完全没有下跌，RSI 为 100；完全没有上涨时为 0；价格完全不变导致分母为零时，应设为缺失或使用明确约定。

有些软件使用简单滚动均值而不是 Wilder 平滑，所以同样写“14 日 RSI”也可能数值不同。研究中应固定初始化与平滑方法。

##### RSI 真正表达什么？

RSI 接近 100，表示近期绝大部分绝对价格变化来自上涨；接近 0 则相反。它是有界动量指标，不是估值指标。

传统上把 70 以上称为“超买”、30 以下称为“超卖”，但这两个词容易误导：

- 超买不表示股票太贵；
- 超卖不表示公司价值被低估；
- 强趋势中 RSI 可以长期高于 70；
- 恶化趋势中 RSI 可以长期低于 30。

使用 RSI 至少有两种相反假设：

1. **均值回归**：低于 30 后买入，预期短期反弹；
2. **动量确认**：突破 50 或进入高位后买入，预期趋势延续。

二者不能同时靠直觉成立，必须分别写成策略并在不同市场状态下检验。

##### RSI 的参数和失效

短窗口更灵敏，极值更多，交易频率也更高；长窗口更平滑。RSI 使用绝对价格变化而不是百分比变化时，同一股票跨除权点可能失真，跨股票也不宜直接比较未经处理的中间量。

价格创新低而 RSI 未创新低的“底背离”只是价格路径的二次变换。若峰谷由事后观察选择，几乎无法进行无偏回测。

#### 布林带：价格相对局部均值和波动的位置

##### 定义

设窗口长度为 $L$ ，中轨为：

```math
M_t=\mathrm{SMA}_{t,L}.
```

价格水平的滚动标准差为：

```math
s_t=\sqrt{\frac{1}{L}\sum_{j=0}^{L-1}(C_{t-j}-M_t)^2}.
```

上下轨为：

```math
U_t=M_t+ks_t,
\qquad
B_t=M_t-ks_t.
```

常见参数是 $L=20,k=2$ 。软件可能使用总体标准差、样本标准差或不同平滑方法，因此边界会略有差异。

两个有用的派生指标是价格位置：

```math
\%B_t=\frac{C_t-B_t}{U_t-B_t},
```

以及相对带宽：

```math
\mathrm{Bandwidth}_t=\frac{U_t-B_t}{M_t}.
```

`%B` 大于 1 表示价格高于上轨，小于 0 表示低于下轨。带宽小表示近期价格水平波动较窄。

##### 同一个布林带可以支持相反策略

**均值回归解释**：价格跌破下轨后买入，预期回到中轨。

**突破解释**：价格突破上轨且带宽扩大后买入，预期新趋势开始。

触及边界本身并不能决定采用哪一种解释。需要用趋势过滤、成交量、市场状态或预先定义的策略假设区分。

##### “两倍标准差”不是 95% 保证

布林带计算的是重叠窗口内价格水平的标准差，而价格水平通常非平稳，金融收益又有厚尾、波动聚集和跳跃。因此不能机械套用正态分布的 95% 覆盖解释。

价格连续沿上轨运行不是计算错误，而是趋势存在时均值和标准差都在移动。所谓“缩口后必然大涨”也不成立；低波动后可能向上、向下或继续低波动。

#### ATR：波动尺度，不是方向信号

##### 从 True Range 到 ATR

前文定义的 True Range 同时考虑日内高低差和隔夜跳空：

```math
\mathrm{TR}_t
=\max\{H_t-L_t,|H_t-C_{t-1}|,|L_t-C_{t-1}|\}.
```

常见 14 日 Wilder ATR 为：

```math
\mathrm{ATR}_{t,n}
=\frac{(n-1)\mathrm{ATR}_{t-1,n}+\mathrm{TR}_t}{n}.
```

为了跨股票比较，可计算：

```math
\mathrm{NATR}_{t,n}
=100\times\frac{\mathrm{ATR}_{t,n}}{C_t}.
```

ATR 只告诉你近期价格通常移动多大，不告诉你向上还是向下。涨停和跌停都能提高 ATR。

##### ATR 的合理用途

- 用均线差除以 ATR，比较信号相对噪声的大小；
- 设置波动缓冲带，减少微小交叉；
- 估算止损距离，例如入场价减若干 ATR；
- 根据风险预算调整仓位，使高波动股票仓位较低；
- 把不同价格股票的波动统一到百分比尺度。

一个简化的风险仓位关系为：

```math
w_t\propto\frac{\sigma_{\mathrm{target}}}{\mathrm{NATR}_{t,n}}.
```

必须设置单票上限和组合约束。ATR 止损价不是保证成交价；跳空和连续跌停时，实际损失可以明显超过若干 ATR。

计算 ATR 时，高、低、前收盘必须采用一致的复权口径。复权价格与未复权高低价混用会制造虚假波动。

#### OBV 与量价指标

##### OBV 的定义

OBV 按收盘涨跌给全部日成交量加正负号并累加：

```math
\mathrm{OBV}_t
=\mathrm{OBV}_{t-1}
+\mathrm{sign}(C_t-C_{t-1})V_t.
```

若收盘不变，常见实现令增量为零。OBV 的绝对起点是任意的，真正可比较的是变化、斜率或相对自身历史的位置，而不是不同股票的 OBV 绝对值。

##### OBV 能说明什么？

它试图表达“上涨日是否伴随更多成交量”。但它把全天所有成交量按收盘涨跌赋予同一个符号：

- 当日先大跌后反弹并微涨，全部成交量仍记为正；
- 大涨 10% 和微涨 0.01% 都把全部成交量记为正；
- 每笔成交本来同时有买卖双方，OBV 不是净资金流。

因此，OBV 是粗糙的有符号成交量累积，不是主力持仓。常见“价格创新高但 OBV 未创新高”的背离也必须用程序化峰谷规则验证。

成交量在拆股、送股、供应商单位变化时可能产生断点。跨股票研究可使用成交额、换手率或成交量相对自身历史的标准化值。

##### MFI 也不是真实资金流

Money Flow Index 常先定义典型价格：

```math
\mathrm{TP}_t=\frac{H_t+L_t+C_t}{3},
```

再定义原始资金量：

```math
\mathrm{MF}_t=\mathrm{TP}_tV_t.
```

按照典型价格相对前一日上涨或下跌，把 MF 分为正负两组，再计算类似 RSI 的 0--100 指标。它本质上是“典型价格方向加权的成交额振荡器”，并没有识别账户资金流入流出。

#### 其他常见指标

##### ROC 和时间序列动量

$L$ 日变化率为：

```math
\mathrm{ROC}_{t,L}=\frac{C_t}{C_{t-L}}-1.
```

这是最透明的动量指标。相比均线，它直接比较两个端点；相比 RSI，它保留收益幅度和正负号。只比较端点会忽略窗口内路径，因此可同时研究路径波动或最大回撤。

##### Donchian 突破

过去 $L$ 日最高价和最低价为：

```math
H^{\mathrm{DC}}_{t,L}=\max(H_{t-1},\ldots,H_{t-L}),
```

```math
L^{\mathrm{DC}}_{t,L}=\min(L_{t-1},\ldots,L_{t-L}).
```

若 $C_t>H^{\mathrm{DC}}_{t,L}$ ，可定义向上突破。公式刻意只使用 $t-1$ 以前的高点；若把当天最高价包含在窗口内，再声称收盘突破当天窗口最高价，定义和时序可能自相矛盾。

突破策略与双均线都是趋势跟随，但前者关注历史极值，后者关注平滑尺度差。突破信号通常更稀疏，也容易在假突破后快速回撤。

##### 随机指标

窗口内收盘位置可写为：

```math
\%K_t
=100\times
\frac{C_t-\min(L_{t-L+1},\ldots,L_t)}
{\max(H_{t-L+1},\ldots,H_t)-\min(L_{t-L+1},\ldots,L_t)}.
```

它接近 100 表示收盘靠近窗口高位，接近 0 表示靠近窗口低位。若窗口最高价等于最低价，分母为零，应设为缺失。常见的 %D 是 %K 的移动平均。

随机指标和前文 CLV 都描述区间位置，只是窗口不同。它同样既可被解释为动量，也可被解释为超买超卖，方向取决于事先提出的假设。

##### ADX：趋势强度而非方向

先从相邻两日高低价构造正向移动和负向移动。若当日最高价上移幅度更大且为正，则记为 $+\mathrm{DM}$ ；若最低价下移幅度更大且为正，则记为 $-\mathrm{DM}$ ，另一方向记零。

记 $\mathrm{WS}$ 为 Wilder 平滑，平滑后定义：

```math
\mathrm{DI}_t^+
=100\times\frac{\mathrm{WS}(\mathrm{DM}^+)_t}{\mathrm{ATR}_t},
```

```math
\mathrm{DI}_t^-
=100\times\frac{\mathrm{WS}(\mathrm{DM}^-)_t}{\mathrm{ATR}_t}.
```

方向差异为：

```math
\mathrm{DX}_t
=100\times
\frac{|\mathrm{DI}_t^+-\mathrm{DI}_t^-|}
{\mathrm{DI}_t^++\mathrm{DI}_t^-}.
```

ADX 是 DX 的 Wilder 平滑。ADX 高表示某一方向的移动相对另一方向更占优势，但不告诉你趋势向上还是向下；方向要看 $\mathrm{DI}^+$ 与 $\mathrm{DI}^-$ 或价格本身。

ADX 常被用作趋势策略过滤器，但它又增加了窗口和阈值参数。固定的 20、25 等阈值没有跨市场普适保证。

#### 指标之间的信息重复

| 指标 | 主要输入 | 数学本质 | 最接近的简单基线 |
| --- | --- | --- | --- |
| 双均线 | 收盘价 | 两种平滑尺度之差 | 多窗口收益 |
| MACD | 收盘价 | 两种 EMA 之差再平滑 | 双 EMA |
| RSI | 收盘变化 | 上下变化幅度占比 | 短期收益与胜率 |
| 布林 %B | 收盘价 | 距局部均值的标准化位置 | 滚动 z-score |
| ATR/NATR | 高低收 | 含跳空的平滑极差 | 滚动波动率 |
| OBV | 收盘方向、成交量 | 收益符号加权成交量累积 | 带符号成交量 |
| MFI | 高低收、成交量 | 价格方向加权成交额比例 | RSI 加成交量 |
| Donchian | 高低收 | 相对滚动极值的位置 | 近期最高价距离 |
| 随机指标 | 高低收 | 窗口区间归一化 | CLV |

对机器学习尤其要避免“指标动物园”：几十个技术指标可能只由收盘价的几个窗口重复生成。建议先对特征做相关矩阵、层次聚类、置换检验和消融实验，再决定保留哪些。

树模型的特征重要性也不能证明指标拥有独立信息。若移除所有简单收益和波动特征后，复杂指标的重要性才出现，可能只是模型需要它来恢复被删掉的基础变量。

#### 把技术指标变成科学实验

##### 先写信号卡

每个技术策略至少写清：

1. 输入字段和复权口径；
2. 窗口、平滑方法和初始化；
3. 状态规则与事件规则；
4. 信号在哪个时刻最终形成；
5. 最早委托时刻和成交价格模型；
6. 涨跌停、停牌和未成交如何处理；
7. 仓位、退出、最大持有期和风险限制；
8. 参数一共尝试了多少组。

##### 不只看“命中率”

趋势策略可能胜率不高，但依靠少数长趋势获得大收益；均值回归策略可能胜率很高，却在少数持续下跌中损失巨大。应同时报告：

- 平均收益与收益中位数；
- 盈亏比和利润因子；
- 持有期与交易频率；
- 最大连续亏损和尾部损失；
- 最大回撤及恢复时间；
- 市场、行业、规模和波动暴露；
- 扣除成本后的收益；
- 无法成交和部分成交比例。

##### 参数稳定性比最优参数更重要

不要只寻找 Sharpe 最高的窗口。应画出快慢窗口、阈值和成本组成的参数曲面，检查相邻参数是否给出相近结论。

推荐的时间检验顺序是：

1. 训练期提出并有限度调整规则；
2. 验证期选择参数族而非单点；
3. 锁定规则；
4. 在最终测试期只运行一次；
5. 用 walk-forward 检查不同年代；
6. 最后用模拟盘比较回测成交和真实可成交价格。

随机打乱日序列会破坏趋势、波动聚集和市场制度变化，不适合作为主要时间序列验证方法。

#### A 股中特别容易踩的坑

- **复权与执行混淆**：复权价格适合连续信号，原始价格用于真实委托、涨跌停和费用；两者要通过公司行动正确连接；
- **涨跌停可交易性**：收盘产生买入信号后，次日一字涨停可能买不到；卖出信号后连续跌停也不能离场；
- **停牌与缺失值**：不要把停牌日向前填充后当作正常零收益交易日计算均线和成交；
- **上市初期预热**：慢均线尚无足够历史时不能产生有效信号；
- **T+1**：盘中买入后出现反向信号也不能当天卖出；
- **现金收益**：长期空仓策略应给现金配置与回购利率设定明确口径；
- **指数成分变化**：横截面技术选股必须使用当时股票池，不能只对今天仍上市的股票回测；
- **参数跨制度变化**：涨跌幅制度、交易费用和市场参与结构会改变信号统计性质；
- **小盘容量**：技术图形可能漂亮，但成交额不足时净收益无法实现；
- **收盘价成交幻觉**：用收盘数据形成信号又按同一收盘价大额成交，是典型未来信息问题。

#### 建议学习顺序

1. 先实现价格高于单均线；
2. 再实现 20/60 双均线状态与交叉事件；
3. 加入交易成本、T+1、停牌和涨跌停；
4. 比较 SMA 与 EMA，不先假定谁更好；
5. 用 ROC 作为最简单动量基线；
6. 再研究 MACD，检查它是否超越双 EMA；
7. 分别用 RSI 做均值回归和动量确认，比较相反假设；
8. 用布林带比较回归和突破；
9. 用 ATR 做风险标准化，而不是预测方向；
10. 最后加入成交量指标，并检验是否有超出价格本身的增量信息。

完成这条路径后，再使用机器学习组合技术指标。否则模型很可能只是用更复杂的方式重新发现“近期涨了多少”和“近期波动多大”。

### 全市场指标：不要只看上证指数

#### 市场宽度

设当日可交易股票中上涨、下跌和平盘家数为 $N_+,N_-,N_0$ ：

```math
\mathrm{Breadth}_t=\frac{N_+-N_-}{N_++N_-+N_0}.
```

还可以看：

- 上涨家数占比；
- 创 20 日、60 日、250 日新高和新低的家数；
- 位于 20 日或 200 日均线上方的股票占比；
- 涨停、跌停、炸板和连续涨停家数；
- 各行业上涨占比；
- 全市场中位数和等权收益。

市值指数上涨但大多数股票下跌，说明上涨集中在少数大权重股；指数变化不大而上涨家数广泛，说明中小股票可能更强。

股票池必须使用当日真实可交易证券，并明确是否排除新股、ST、停牌、北交所和当日无成交股票。否则宽度历史会受到退市和幸存者偏差污染。

#### 横截面离散度和相关性

全市场个股收益的稳健离散度可用中位数绝对偏差：

```math
\mathrm{Dispersion}_t
=1.4826\times\mathrm{median}_i|r_{i,t}-\mathrm{median}_j(r_{j,t})|.
```

离散度高表示个股表现分化，可能有利于横截面选股，也可能来自小盘异常波动。市场压力期个股相关性常上升，分散化效果会下降。

#### 全市场成交和拥挤

可跟踪：

- 沪深总成交额及相对过去同一时刻的比例；
- 全市场和各行业换手率分位数；
- 成交额集中在前 10、50、100 只股票的比例；
- 小盘与大盘、成长与价值的相对成交活跃度；
- 价格涨跌与成交拥挤是否集中于少数主题。

总成交额上升说明交易活动增加，不自动表示“场外新增资金入市”。杠杆、持仓周转和同一资金反复交易都能提高成交额。

#### 融资融券、ETF 份额和股东数据

这些数据比纯量价多一层持仓或资金线索，但都有时滞和口径：

- **融资余额**：反映已披露范围内的融资买入负债存量，不等于全市场杠杆；
- **融资买入额**：是流量，不能和融资余额这个存量混用；
- **ETF 份额变化**：申购赎回导致份额改变，比二级市场成交额更接近产品资金净变化，但还需乘净值并处理份额时点；
- **股东户数**：来自定期报告或互动披露，低频且可能滞后；
- **限售解禁、减持和回购**：是潜在供需事件，应按公告日与实际实施日建模。

“有更多信息”不等于“有免费超额收益”。这些数据通常早已被大量参与者观察。

### 怎样判断一个指标是否“科学”

#### 先通过定义审计

对每个指标回答：

1. 原始字段来自交易所、供应商还是自己推断？
2. 公式、单位、分母和缺失值规则是什么？
3. 这个数在什么时候真正可用？
4. 使用快照、逐笔、分钟还是日线？
5. 是否使用未来形成的最高、最低、收盘或全天成交量？
6. 公司行动、停牌、涨跌停、上市和退市如何处理？
7. 不同供应商能否在抽样日期交叉核验？

定义审计不过关，不需要进入机器学习阶段。

#### 再提出可证伪假设

坏假设：

> 高换手说明主力吸筹，未来会涨。

可检验假设：

> 在非上市前 60 日、非涨跌停、过去 20 日日均成交额大于某阈值的 A 股中，今日换手率位于股票自身过去 250 日 95% 分位以上，是否对未来 5 日行业中性收益有增量预测力？

后者明确了股票池、异常条件、历史基线、预测周期和标签，可以被数据否定。

#### 做事件研究而不是看几张图

基本流程：

1. 在每只股票自身历史中定义事件，避免小盘股天然高换手的横截面偏差；
2. 事件发生日收盘后才确认信号，最早次日成交；
3. 计算未来 1、5、10、20 日收益；
4. 减去市场、行业和常见风格暴露；
5. 对事件重叠、同日市场冲击和序列相关使用稳健标准误或分块重采样；
6. 报告均值、中位数、胜率、尾部、换手和成本；
7. 按年份、市场状态、规模和行业做稳定性检查；
8. 把最终规则锁定后只运行一次样本外测试。

#### 检查增量信息

复杂指标应与简单基线比较。例如评估“筹码集中度”时，基线至少包括：

- 过去收益和反转；
- 波动率；
- 换手率和相对成交量；
- 市值、价格和流动性；
- 60 日 Volume Profile 的简单特征；
- 行业与市场收益。

可用线性模型、树模型或非参数分组，但重点是加入复杂指标后，样本外排序、净收益或损失函数是否稳定改善，而不是训练集特征重要性是否好看。

#### 警惕多重检验

如果测试 100 个指标、20 个窗口、10 个阈值和 5 个持有期，偶然出现漂亮结果几乎必然。应：

- 预先写研究假设和主要评价指标；
- 减少等价特征；
- 保留完全未参与调参的最终时间段；
- 使用 walk-forward 而非随机打乱；
- 报告所有尝试，而不只保留赢家；
- 必要时使用 FDR、Deflated Sharpe Ratio 或现实检验等方法校正数据挖掘偏差。

#### 指标有效期与半衰期

实时指标往往预测周期很短。盘口不平衡可能只影响下一次或未来数秒的价格，日换手异常可能持续数日，而基本面信息可能影响数月。将秒级信号拿到次日交易，通常已经衰减；将月频基本面信号用于秒级择时，也不匹配。

可估计不同预测步长 $h$ 下的 IC 或回归系数：

```math
\mathrm{IC}(h)=\mathrm{corr}(x_t,r_{t\rightarrow t+h}).
```

观察其随 $h$ 的衰减、符号变化和置信区间。不要先假定指数衰减；只有形状大致支持时，再拟合半衰期。

## 4. 典型案例

前面的理论中已经包含多个可复现实例。本节给出学习导航，并用 BaoStock 说明免费日频数据能支持哪些案例、不能支持哪些案例。

| 案例 | 核心问题 | 最小对照组 |
| --- | --- | --- |
| 双均线趋势 | 均线交叉是在捕捉趋势，还是仅仅延迟确认已有涨跌 | 买入持有、单均线、随机入场 |
| 换手率异常 | 高换手代表信息到达、分歧还是短期拥挤 | 行业与市值中性换手率 |
| 筹码分布 | 所谓持仓成本是否只是历史成交量的模型化重构 | 直接使用成交量分布 |
| 盘口不平衡 | 买卖盘差异能否在扣除延迟与冲击后预测短期价格 | 中间价变化、价差和深度 |
| 市场宽度 | 指数上涨时有多少股票真正参与 | 等权收益与涨跌家数 |

### 案例：双均线趋势策略的研究闭环

#### 问题与答案

研究问题是：短期均线高于长期均线时，未来一段时间的收益是否更高？

合理答案不是“金叉必涨”，而是：双均线用两个不同时间尺度的低通滤波结果比较近期和较长期价格水平。如果收益存在阶段性持续，状态差可能有条件地识别趋势；如果价格接近随机游走、频繁均值回归或发生跳跃反转，均线的滞后会造成追涨杀跌。它更适合检验趋势是否存在，不适合预测精确拐点。

#### 假设与证伪条件

- **研究假设**：在控制市场、行业、波动率和流动性后，短均线高于长均线的状态对未来收益仍有增量解释力；
- **机制假设**：信息扩散、投资者反应不足和仓位调整使价格在部分状态下缓慢延续；
- **证伪条件**：样本外收益不优于买入持有或单均线基线，参数稍作变化即失效，或成本后收益消失；
- **适用边界**：震荡市场、连续涨跌停、极端跳空和低流动性股票可能显著恶化结果。

#### 数据与时点

初学实验只需要日频开高低收、成交量、复权因子、停牌与涨跌停状态。使用交易日 `t` 收盘价计算两条均线，信号只能在收盘后确定，因此最早使用 `t+1` 的可成交价格。若使用 `t` 收盘成交，回测已经偷看了尚未完成的收盘数据。

同时保存复权价格和不复权价格：前者用于计算连续收益与均线，后者用于判断真实委托价格、涨跌停和成交可行性。股票池必须包含历史退市股票和当时可见的成分，不能只使用今天仍上市的公司。

#### 实验设计

1. 先用一个宽基指数完成最小实验，减少个股停牌和退市处理的干扰；
2. 预先指定少量窗口组合，例如短期 5、10、20 日与长期 60、120、250 日，不在全样本穷举最优参数；
3. 比较买入持有、单均线、双均线和随机保持相同仓位比例四个基线；
4. 分别报告次日开盘、次日均价等可执行价格下的结果；
5. 加入手续费、印花税、滑点、T+1、涨跌停和无法成交处理；
6. 用滚动或扩展窗口选择参数，最后保留一段从未参与选择的样本外时期；
7. 按趋势、震荡、高波动和低波动状态拆分结果，检查收益来自哪里。

#### 怎样解释结果

若策略年化收益上升但最大回撤、换手和尾部损失也明显增加，不能简单说策略更好。若它主要通过牛市持仓、熊市空仓降低回撤，它的价值可能是风险暴露管理，而不是稳定预测每日涨跌。若只有某一个窗口组合有效，应优先怀疑参数挖掘；若相邻参数形成平滑平台、多个市场阶段方向一致且成本后仍成立，证据才更可信。

这个案例最终应交付：数据字典、无前视信号表、交易流水、基线对比、参数热力图、状态分组结果、成本敏感性和一页失败条件总结。双均线是否赚钱不是本课标准；能否清楚解释它在何时、为何有效或失效，才是标准。

### BaoStock 能做到什么，不能做到什么

BaoStock 的定位是免费中国股票**历史数据**工具。其历史 K 线接口可返回 `open`、`high`、`low`、`close`、`volume`、`amount`、`turn` 等字段，适合本教程的日频和部分分钟级入门实验。

它适合：

- 日频收益、振幅、跳空和 ATR；
- 成交量、成交额、换手率和相对成交量；
- 日频流动性代理指标；
- 量价事件研究和低频回测。

它不应被当作：

- 低延迟实时交易行情；
- 完整 Level-2 十档订单簿；
- 逐笔委托、撤单和队列数据；
- 投资者账户持仓成本数据库；
- 可直接实盘下单的券商接口。

开始研究前，对 `turn` 口径、`volume` 单位和 `amount` 单位做实测核验，不要仅凭字段名推断。

#### 第一组建议特征

使用日 K 先做这些透明特征：

```python
import numpy as np
import pandas as pd


def add_market_features(df: pd.DataFrame, lookback: int = 20) -> pd.DataFrame:
    out = df.sort_values(["code", "date"]).copy()
    g = out.groupby("code", group_keys=False)

    out["ret_1d"] = g["close"].pct_change()
    out["gap"] = out["open"] / g["close"].shift(1) - 1
    out["range"] = (out["high"] - out["low"]) / g["close"].shift(1)

    price_range = out["high"] - out["low"]
    out["clv"] = (2 * out["close"] - out["high"] - out["low"]) / price_range
    out.loc[price_range == 0, "clv"] = np.nan

    # 先确认 amount 和 volume 单位兼容，再把结果称为 average_price。
    out["average_price"] = out["amount"] / out["volume"].replace(0, np.nan)
    out["close_to_average"] = out["close"] / out["average_price"] - 1

    out["volume_median"] = g["volume"].transform(
        lambda s: s.shift(1).rolling(lookback, min_periods=lookback).median()
    )
    out["relative_volume"] = out["volume"] / out["volume_median"]

    out["turnover_median"] = g["turn"].transform(
        lambda s: s.shift(1).rolling(lookback, min_periods=lookback).median()
    )
    out["relative_turnover"] = out["turn"] / out["turnover_median"]

    # 成交额缩放不影响横截面排序，但会影响 ILLIQ 的绝对数值。
    out["amihud_illiq"] = out["ret_1d"].abs() / out["amount"].replace(0, np.nan)
    return out
```

这段代码只是特征构造，不是策略。还需要：

- 把字符串字段转成数值并处理空值；
- 排除停牌和异常交易状态；
- 确认复权价格和原始量额的相容性；
- 对股本变化和上市初期单独处理；
- 用 `shift(1)` 保证历史基线不包含当天；
- 把信号生成和次日执行分开。

### 初学者最值得记住的结论

1. 价格和成交反映交易，不等于企业价值；
2. 高换手表示交易活跃，不表示唯一股份完成了等比例换手；
3. 每笔成交同时有买方和卖方，“资金净流入”通常是主动方向分类结果；
4. 挂单表示可撤销意愿，成交才是已发生事实；
5. 五档/十档快照不是完整订单流；
6. 最新价、收盘价、VWAP 和中间价回答的是不同问题；
7. 指数点位可能掩盖大多数股票的真实表现；
8. 技术指标大多是 OHLCV 的变换，不应因名称而获得额外可信度；
9. 公开行情无法恢复所有投资者的真实持仓成本；
10. 筹码分布是模型时，必须披露递推、初始化和成交分配假设；
11. 实时指标的有效周期通常与数据频率相匹配；
12. 一个指标是否有用，只能由无未来数据、样本外、扣成本的实验回答。

## 5. 练习

每项练习都应留下数据字典、计算代码、图表和结论。最低验收标准如下：

1. 指标公式、复权方式、窗口、采样时点和缺失值处理完整记录；
2. 信号与成交价格错开，不能用收盘后才知道的数据在同一收盘价交易；
3. 报告参数敏感性、样本外结果、换手率和成本后收益；
4. 与更简单的价格、波动率、成交量基线比较增量价值；
5. 明确指出该指标是观测量、派生量还是潜变量代理。

### 由浅到深的六个练习

#### 练习 1：换手异常事件研究

**问题**：股票自身高换手后，未来收益、波动和成交是否异常？

- **数据**：BaoStock 日线。
- **特征**：换手率的 250 日滚动分位数。
- **分组**：高换手上涨、高换手下跌、高换手小涨跌。
- **输出**：未来 1/5/20 日行业中性收益、波动率和换手衰减。
- **重点**：高换手不预设方向。

#### 练习 2：收盘相对成交均价

**问题**：收盘显著高于当日平均成交价，是短期延续还是反转？

- **数据**：日线量额，先核对单位。
- **特征**：`close / average_price - 1`。
- **控制**：当日收益、振幅、换手、市值和行业。
- **重点**：检查该特征是否只是当日收益的另一种表达。

#### 练习 3：市场宽度状态机

**问题**：同样的指数收益，在宽度强和宽度弱时，未来风险是否不同？

- **特征**：上涨占比、新高新低差、等权减市值加权收益、横截面离散度。
- **输出**：四种市场状态下的未来指数收益、回撤和行业轮动。
- **重点**：历史股票池和退市股票必须完整。

#### 练习 4：Volume Profile 与筹码模型对比

**问题**：复杂筹码递推是否比简单滚动成交量分布更有用？

- **模型 A**：过去 60 日按日均价和成交量构造价格分布。
- **模型 B**：使用换手率递推旧筹码衰减。
- **评价**：对未来收益、波动和成交的样本外增量预测。
- **重点**：敏感性分析初始化、分桶、窗口和换手分母。

#### 练习 5：盘口不平衡

**问题**：五档 OBI 对未来 1 秒、10 秒、1 分钟中间价变化的预测如何衰减？

- **数据**：合规获得的带时间戳 Level-1/Level-2 快照。
- **评价**：方向准确率、回归系数、价差、延迟和交易成本。
- **重点**：按股票和交易时刻标准化，单独处理涨跌停。

#### 练习 6：从信号到执行

**问题**：一个日频选股策略在不同成交额参与率下还能剩多少收益？

- **过程**：对每笔换仓限制为 ADV 的 1%、2%、5%，加入价差和非线性冲击。
- **输出**：净收益、成交天数、未完成订单、最大容量。
- **重点**：预测正确不等于能按回测价格成交。
